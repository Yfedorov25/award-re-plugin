## 2. Контейнер-setup (без Claude Browser pane — це НОРМА)
```
npm i playwright && npx playwright install chromium
node scripts/serve-skeleton.mjs springs-home --port 8873 &
```
- Прибери `PLAYWRIGHT_FROM=...` з усіх команд (resolveChromium має фолбек на
  звичайний require). Якщо десь у скриптах хардкод — постав змінну на
  локальний `node_modules`.
- **Візуал БЕЗ браузера:** дивись PNG через `Read`:
  - наш рендер: `extraction/springs-home/visual/parity/desktop-s<N>-ours-1440x900.png`
  - ціль (live): `extraction/springs-home/visual/live/desktop-s<N>.png`
  - хітмап дифу: `extraction/springs-home/visual/parity/desktop-s<N>-diff-1440x900.png`
- **Зонди движка/DOM:** крихітний `page.evaluate` у playwright-скрипті
  (движок дає `__ENGINE__()`, `__ENGINE_BINDINGS__()`, `__ENGINE_UNRESOLVED__`).
- Live springs.estate має бути доступний з контейнера (перевір `curl -I`).
