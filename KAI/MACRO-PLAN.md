## 🅱️ ТОЧКА Б ОДНИМ РЕЧЕННЯМ (фінальний тест системи)

> У системи є **структурований каталог пазлів** (компоненти · композиції · секції · шви · переходи · прийоми · копірайт · сенси · грама), витягнутий з **десятків топ-сайтів**. На запит «зроби сайт для проєкту X» система **сама підбирає стек** {прийоми + шви + грама + палітра + копірайт} з обґрунтуванням «бо проєкт такий» і **будує сайт award-рівня** — за токен-гейтом, без нагадувань Єгора.

Це **Б-2.4** (див. STATE § ТОЧКА Б). AIR, галерея, автономія — ЗАСОБИ до цього тесту.

**Три речі, які роблять цю точку Б, а не «повторити AIR»:**
1. Система вчиться не тільки *елементи* повторювати, а **як побудовані сенси, копірайт, композиції, шви, переходи, ідея**.
2. Галерея — не архів, а **словник, з якого компонують нове**.
3. Механізм **самомасштабується**: кожен новий сайт → розкладається на пазли → пазли в базу → каталог багатшає → наступний сайт легше.

## 🔄 ЦЕНТРАЛЬНИЙ МЕХАНІЗМ — «ЦИКЛ САЙТУ» (серце всієї системи)

Уся система = повторення ОДНОГО циклу над чергою сайтів. Кожен сайт проходить 4 кроки:

```
   ┌─────────────────────────────────────────────────────────────┐
   │  ЦИКЛ САЙТУ (повторюється для кожного сайту в черзі)          │
   │                                                              │
   │  1. РЕПЛІКА 1-в-1   →  відтворити сайт покадрово (як AIR)     │
   │                        desktop + mobile, екзамен «два вікна»  │
   │                                                              │
   │  2. РОЗКЛАД НА ПАЗЛИ →  розібрати готову репліку на:          │
   │        компоненти · композиції секцій · шви · переходи ·      │
   │        прийоми · КОПІРАЙТ · СЕНСИ (чому так) · грама/палітра  │
   │                                                              │
   │  3. ЗАПИС У БАЗУ    →  кожен пазл = картка в галереї          │
   │        {назва · тип · прийом(T-ID) · сайт-джерело ·           │
   │         коли застосовувати · числа(ease/px/ms/hex) ·          │
   │         self-contained HTML · сенс «навіщо це працює»}        │
   │                                                              │
   │  4. ГАЛЕРЕЯ РОСТЕ   →  борд показує новий пазл; каталог       │
   │        стає багатшим словником для КОМПОЗИЦІЙНОГО ЗАПИТУ      │
   └─────────────────────────────────────────────────────────────┘
              ↓ повторити для наступного сайту з черги ↓
      коли каталог достатньо багатий → ТЕСТ Б-2.4 (композиційний запит)
```

**Закон циклу** (зі STATE): репліка БЕЗ розкладу на пазли = марна робота. Крок 2-3 обов'язкові — інакше система не вчиться компонувати, а просто копіює.
