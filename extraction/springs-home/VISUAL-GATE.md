# VISUAL-GATE — поріг піксельної звірки S5 (зафіксовано ДО прогону)

Дата фіксації: 2026-07-11, ДО першого запуску springs-visual-diff.

## Метод
Живу сторінку жестами (CDP, як animation-map) проводимо по снап-станах; на кожному
ОСІЛОМУ стані — скріншот + сторінковий s (проба-одометр = корінь intro, чистий потік).
Інтро-стани hero — окремо по cumulative input. Нашу сторінку виводимо в ТУ САМУ позу
через `?s=N` / `?intro=I` (движок детерміновано ставить позу — та сама, що дає скрол,
криві вже доведені CURVES-GATE 6/6). Дифи — `scripts/visual-parity.mjs` (canvas-diff,
per-pixel RGB distance 32/255), борд у extraction/springs-home/visual/parity/.

## Пороги (per стан × вʼюпорт)
- **PASS: diff ≤ 2%** (закон verdict-gate) при `--erode 5` (AA-стеля шрифтів/фото —
  задокументована межа тулзи; сирий diff без erode теж пишеться в звіт — довідково).
- Маски в ПЕРШОМУ прогоні: ЖОДНИХ (чесна картина). Очікувані порушники фіксуються
  списком; маски/заміни — окремим рішенням після розбору.

## Очікувані чесні розбіжності (зафіксовано ДО прогону)
1. WebGL-сцени живого (l-wellness__webgl, nature/place підкладки) — у нас no-WebGL
   (закон 4): дифи цих зон будуть; рішення — шар-заміна в S5/S6, не маскування мовчки.
2. Відео (l-place-video) — кадр відео недетермінований.
3. Живі reveal/паралакси в русі виключені: знімаємо лише ОСІЛІ стани.

## Мірило
Стан = PASS/FAIL; звіт per-стан у VISUAL.md + agregate. «Добито» для борда Єгору =
всі стани зони hero/intro/wellness ≤2% (або чесний розбір залишку по зонах).
