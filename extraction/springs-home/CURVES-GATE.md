# CURVES-GATE — поріг звірки кривих S3 (зафіксовано ДО прогону)

Дата фіксації: 2026-07-11, ДО першого запуску curve-compare проти нашої сторінки.

## Метод
Той самий `animation-map.mjs` знімає НАШУ сторінку (`--origin http://localhost:8873
--out extraction/springs-home/ours/...`) з тими ж дефолтами (36 кроків, 2.5vh),
що знімав живу. `curve-compare.mjs` матчить цілі live↔ours за сигнатурою
(tag + перетин класів + текст) і порівнює криві.

## Параметризація
- **Скрол-фаза**: криві параметризовані ОДОМЕТРОМ s (не інпутом) — снап-підмножина
  прогону варіюється між запусками навіть на живому (S3-розкопка: hero-прогін
  бачив 1170/2671, intro-прогін 900/2970 — обидва легітимні стани живого движка).
  Порівняння в осілих s-точках ЖИВОЇ карти; наше значення = лінійна інтерполяція
  наших семплів (осілі + transient) по s. Вісь s кожного прогону — власний одометр
  (max-range проба); порівнюваність осей гарантована реплікою травела кореня.
- **Інтро-фаза hero (s≈0)**: параметризація cumulative input; порівняння в осілих
  input-точках живої карти, наше = інтерполяція по input.

## Пороги (на семпл × властивість)
- top/left: |Δ| ≤ 10px
- w/h: |Δ| ≤ max(8px, 2%)
- opacity: |Δ| ≤ 0.1
- clipPath: усі числа шаблону в межах 3 одиниць (px або %), інакше string-рівність

## Гейт (на секцію × вʼюпорт)
- match-ratio: ≥80% цілей живої карти зматчено на нашій
- curve-score: ≥90% перевірок (семпл × властивість) у межах порогу
  (перевіряються властивості з live moving=true: bbox завжди, opacity/clip якщо рухались)
- самоперевірка нашої карти: exit 0 (сторінка реально їде, цілі мають криві)

PASS = усі 3 секції (hero-gallery, intro, wellness) × 2 вʼюпорти проходять усі три умови.

## Відомі виключення (зафіксовані ДО прогону, з причиною)
1. **transform-матриці НЕ порівнюються** — свідомо: live піни/sticky реалізовані
   сумішшю нативного скролу+transform, наша репліка — bbox-еквівалентним розв'язком;
   візуальна істина = bbox+opacity+clip. (Матриці порівняємо в S5-полірі там,
   де вони збігаються за конструкцією.)
2. **Wellness внутрішні слайд-вайпи (часові, при стоячому одометрі)** — в осілих
   кадрах невидимі (clip повертається в спокійний стан), не реплікуються в S3;
   юрисдикція S4 (потрібен таймінг-екстрактор переходів).
3. Інтро-фаза існує лише на desktop hero (на mobile гейта немає — чесний скрол).
