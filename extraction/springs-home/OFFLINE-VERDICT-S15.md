## 🔴 БЛОКЕР СЕРЕДОВИЩА (головне для S16)
- `springs.estate:443` → **egress-політика контейнера ВІДХИЛЯЄ** CONNECT
  (`$HTTPS_PROXY/__agentproxy/status` → `recentRelayFailures: springs.estate,
  connect_rejected, "gateway answered 403 to CONNECT (policy denial)"`).
  README проксі (`/root/.ccr/README.md`): такі 403 — **репортити, не обходити**.
- Наслідок: наш `?s=N` рендер тягне `/assets/` + `/media/` картинки з live через
  проксі-кеш `serve-skeleton` → **кеш ефемерний і порожній у свіжому контейнері,
  долити нема звідки** → свіжий піксель-рендер ours НЕМОЖЛИВИЙ. Так само мертві:
  spec-verify / skeleton-verify (goto liveOrigin), scene-map / animation-map /
  timing-map / intro-timing / live-shots (усі ходять на live), екстракція
  БУДЬ-ЯКОЇ нової сторінки.
- `npx playwright install` теж заблокований (`cdn.playwright.dev:443` denied).
  ОБХІД знайдено (див. Setup) — це НЕ блокер, працює.
- Allowlist самотужки НЕ можна (проксі CONNECT-only, без self-service API);
  cache долити НЕ можна (chicken-and-egg: нема live → нема чим наповнити).
  → потрібна дія власника: **додати `springs.estate` в egress-allowlist**
  середовища, або свідомо лишатись в офлайн-режимі.
