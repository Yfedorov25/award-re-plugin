# LOCATION - база секції ЗАКРИТА: 6 варіантів, round-5 (2026-07-04)

Секція «Локація» (с. Агрономічне). Сенс: показати дуже круто, що є поруч - назвами і числами,
зрозуміло людині за 3 секунди. Пройшла 5 раундів; фінал = копі-першою + жива карта + мало підписів.
Галерея: all-prototypes.html. Всі самодостатні (дані embedded; CDN лише fonts+GSAP, як у всій базі).

## 6 варіантів (кожен = ІНШЕ людське питання, не інший механізм)
- **loc-1 «Все поруч»** (постер, нуль кліків) - «що тут є?». 7 підписаних POI прямо на карті, пунктири
  від дому, вікна мерехтять.
- **loc-2 «Пішки чи автом»** - ФЛАГМАН (камера-dolly) - «наскільки я звʼязаний з містом?». Тумблер:
  авто -> viewBox твін [120,-20,1060,660]->[-30,-1325,2681,2115] (2.5x, 1.2с power2.inOut), макро-шар
  Вінниці проявляється (246 реальних доріг + пляма міста), дальні POI народжуються з підписами
  (Tennis Hall 7хв, Artfox 8, ОККО 6 - канонічні числа з live smarts). Село стає куточком. Мікро->макро.
- **loc-3 «Список і маршрут»** - «як саме я дійду?». Оригінал smarts (власник любить): список 7 POI,
  клік -> Dijkstra-маршрут + walker + лічильник. Двостороння підсвітка.
- **loc-4 «Район, вулиця, ділянка»** (план-дрил) - «де саме мій дім?». Три рівні морфом (маска від
  якоря), 22,5 сотки dimension-line. Фікси: pointer-events (h2 не перехоплює), safe-frame, name-pills.
- **loc-6 «Категорії»** (агрегація) - «чи вистачає інфраструктури?». Чіпи з числами, топ-3-4 + кластер
  «ще N» (quadro INFRA-модель). Однотипні розрізняються назвою («Траш · 3 хв»/«Грош · 15 хв»).
- **loc-9 «Акварель»** (hover-reveal) - «яка тут атмосфера?». Справжні feTurbulence+feDisplacementMap,
  фото-віньєтки крізь oval-mask, collision-placer.

## ЗАКОНИ СЕКЦІЇ (кров'ю 5 раундів; повні в memory: award-map-few-poi-law)
1. **5-8 підписаних POI, НІКОЛИ десятки** (round-3 вивалив 48-59 = нечитабельно; smarts=6, quadro=8).
   Маса -> чіп категорії + кластер-число.
2. **ЖИВА КАРТА != мало підписів** (round-4 викинув 823 будівлі = чорна пустка). Building-layer +
   FNV-світні вікна + зелень/вода/назви = обов'язкова текстура КОЖНОГО варіанта.
3. **Авто = справжнє мікро->макро**: viewBox-твін (НЕ CSS scale) + макро-геометрія в даних (без неї
   розширення = порожнеча). Дальні маршрути по трасі, не діагональ.
4. **Підпис = ТИП+хв** («Супермаркет · 3 хв»), назва вторинна. Нуль голих кружечків.
5. **Колізії: нуль перетинів лейблів** (PillPlacer bbox; Playwright-гейт).
6. **Лічильники ніколи 0**; заявлені N місць = N видимих без скролу; rest-state не порожній.
7. **Копі-тон**: констатація користі + інструкція дією + реальні числа. НУЛЬ афоризмів
   («Район, як він є» = слоп). Канонічні авто-числа: Вінниця 5хв · ОККО 6 · Tennis Hall 7.
8. Керований клік, не форсований скрол (F-19); interaction-моделі різні за ПИТАННЯМ, не віджетом.

## Гейт пройдено (Playwright, 2026-07-04)
Всі 6: будівлі 823 (loc-4: 1010 своїм движком) · колізії 0 · нуль-лічильників нема · деші 0 ·
копі дослівно затверджена. Флагман: viewBox твін до drive-box підтверджено посемплово
(300ms/800ms/1500ms), кільце гасне, mode=drive.

## Історія раундів (уроки)
R1-R2: механіка не реагувала (одометри no-op, opacity-toggle замість появи). R3: 48-59 POI =
нечитабельний інвентар (ГОЛОВНА помилка). R4: закон «мало POI» застосували до карти -> викинули
будівлі -> чорна пустка; колізії; «0 хв»; Вінниця без геометрії. R5: копі-першою + закон живої карти
+ 3 шари даних = закрито. Порядок питань власника > новизна механізмів: «Список і маршрут» повернуто
попри вердикт ради про «ре-скін» - людська ясність важливіша.
