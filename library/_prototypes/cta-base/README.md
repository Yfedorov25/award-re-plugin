# CTA - база секції: ДЕСКТОП ЗАКРИТО (вердикти власника 2026-07-02, 2 раунди)

Фінальна база: 6 варіантів (2 smarts + 4 towns), всі = ОДИН ЕКРАН 100vh, темні, «ви»-голос.
Галерея: all-prototypes.html.

## Smarts (ЖК Агрономічне)
- **cta-1 «Ключі на столі»** - Springs l-callback: вечірній ext-02 full-bleed, форма без боксу
  на медіа, push-swap голосів квартира/комерція (voice/chip/button/undecided вікна).
- **cta-10 «Рефрен»** - word-slot (одна нода, translateY-стрічка) грає РАЗ «Смарт 24 -> Смарт 27
  -> Оберіть свою.» і завмирає; ghost-плита 8%; residential-голос.

## Towns (вул. Замкова)
- **cta-7 «Вечірня панель»** - arch-entry-dusk тримає екран, темна панель праворуч з формою,
  tel-верб першим; морф = panel-border dashoffset draw раз на вході.
- **cta-8 «Число-вхід»** - одометр $67 000 грає раз (digit strips, одна величина), ряд contained
  як тихий доказ, «Всі шість зараз вільні» = чесний фрейм.
- **cta-9 «Ключі на столі · towns»** - граматика переможця cta-1 на towns (hero-day + dusk-tint),
  один голос, tel-верб.
- **cta-11 «Приїдьте подивитись»** - запрошення на землю: адресна плита з pin-glyph draw,
  маршрут-пілюлі GMaps/Waze, форма = другорядний шлях. Нуль фейк-карт.

## Спільний ФОРМА-АТОМ (в усіх 6, контракт)
2 поля (Імʼя/Телефон) + consent + чіп юніта (X >=44px, порожній стан веде в пікер) + синхронна
маска +380 + honeypot + повні стани (focus/busy з dashoffset-лінією по периметру кнопки поки
запит летить/error per-kind з резервом місця/success) + ЧЕСНИЙ submit через Promise (провал =
реальний телефон на towns, чесний retry на smarts) + штора-успіх (clip-path + self-draw чек +
наступний крок) + reduced-motion повний + data-cta-variant/data-conv + GA4-коментарі.
