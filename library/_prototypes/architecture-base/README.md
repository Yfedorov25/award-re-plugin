# ARCHITECTURE - база секції: 3 суперкомпозиції, round-2 (2026-07-04)

Секція «Архітектура». Сенс: показати дім так, щоб людина зрозуміла і повірила за 3 секунди.
Це ДОДАТКОВІ варіанти до існуючих 12 сильних у лінії (hover-the-building, collage-inspect,
veil-detail, spec-builds...) - нічого не замінюють. 6 слабких старих вбито ще до раунду
(3 день/ніч = один трюк x3; 3 матеріальні = дублі collage-inspect/section-accordion).
Галерея: all-prototypes.html. Самодостатня папка: атоми в technique-code/, кадри в renders/.

## 3 варіанти (кожен = ІНШЕ людське питання + СУПЕРКОМПОЗИЦІЯ з >=3 атомів)
- **A1 «Вечір вдома»** (дім 1, цегляний, dn-ext пара) - «яким тут буде вечір?».
  Вікна загоряються ПО ОДНОМУ (атом із tuned-координатами, x:9/31/46/62/79), біля кожного
  пілюля життя («Кухня. Вечеря.» ...), одна в кадрі за раз. Payoff: канон піднімає повний
  присмерк, ліхтарі вздовж доріжки, фінальний рядок.
  atoms: daynight-masked-windows (ЯДРО) + daynight-engine (канон) + content-stage-cascade.
- **A2 «Чому він такий»** (дім 2, QUADRO-модерн) - «чому дім виглядає саме так?».
  Медіа-степер 5 біт: констатація великим serif веде, кадр-доказ на повний блід доводить.
  Граматика збірки = spec-builds (bundle-6).
  atoms: media-step-switch (ЯДРО) + blur-reveal-stagger-title + corner-frame-meta.
- **A3 «З чого збудований»** (дім 2, ПОСТЕР, нуль кліків) - «з чого?».
  Едиторіал-постер: 4 макро в scale-драбині (50/40/64/42%), wordmark-план позаду,
  pointer-дрейф глибини, de-bleed кода. Граматика = collage-inspect без inspect-лінзи.
  atoms: parallax-collage (ЯДРО) + split-word-headline + de-bleed.

## ЗАКОН СЕКЦІЇ - F-57 (кров'ю round-1)
**Claude Design вигадує двійники атомів, якщо дати лише "натхнення".** Round-1 проігнорував
заллятий атом і написав власні вікна з ВИГАДАНИМИ координатами + чужі шрифти (Cormorant+Manrope).
Round-2 фікс, обов'язковий для БУДЬ-ЯКОЇ секції через Claude Design:
1. ПОВНИЙ арсенал атомів З КОДОМ у fenced-бандлах (bundle-1..5, 29 атомів) - не лише потрібні.
2. reference-combos як ГРАМАТИКА збірки (як атоми компонуються, не що копіювати).
3. Жорсткий гейт: grep сигнатур атомів + по-числове порівняння tuned-даних + atoms_used>=3 +
   house-шрифти (Fraunces+Inter) + house-ease cubic-bezier(.25,.74,.22,.99).

## Гейт пройдено (Playwright, 2026-07-04)
- Атоми справжні: window.DayNightMaskedWindows/MediaStepSwitch/ParallaxCollage створюють DOM
  (5 tuned-вікон, 5 моментів степера, 4 клітинки колажу).
- A1 драматургія: rest = день+заголовок, мідскрол = 4 вікна + РІВНО 1 пілюля (collision-safe),
  фінал = всі горять + канон-ніч 0.96 + рядок про ліхтарі.
- A2: 5/5 рядків копі дослівно; перший заголовок sharp у rest; 1 видимий момент за раз.
- A3: 5/5 слів заголовка, 4 підписи дослівно, колізії bbox = 0.
- Всі: Fraunces+Inter, деші у видимому тексті = 0, консоль чиста.
