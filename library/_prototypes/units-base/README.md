# UNITS - база секції ЗАКРИТА: десктоп + мобайл (вердикти власника 2026-07-02)

Фінальна база: 6 варіантів (3 smarts + 3 towns) x 2 формати.
Галереї: all-prototypes.html (десктоп) · all-prototypes-mobile.html (телефонний індекс).
Мобільні твіни (round 4): units-{1,2,11,16,17,20}-mobile.html - phone-канвас 430px,
overflow-x:CLIP (hidden ламає sticky), 100dvh, тап-цілі >= 44px, копі = десктопна 1:1.
Мобільні уроки цього раунду: (1) sticky-тір МУСИТЬ вміщатись у 100dvh на 390x844 - контент
понад вьюпорт під sticky top:0 стає недосяжним (fix: тір I/II 997/953px -> 844px рівно);
(2) розмірні лінії/FLIP переанкерюються під портретний cover rect, лінії поза кропом дропаються.

## Smarts (ЖК Агрономічне, 54 квартири 2 форматів + комерція)
- **units-1 «Список і план»** - Ever dual list/plan FLIP: список форматів -> розворот у плиту поверху,
  вош-ноди летять зі слотів списку в band-оверлеї плити (transform-only FLIP), чипи-фільтри димлять
  іншу типологію в обох вʼю. Копі-пас round-3: місток «Обери свою квартиру.» + факти.
- **units-2 «Колекції»** - r1864 collection tiers: три зібрання (Смарт 24 / Смарт 27 / Комерція),
  P1 curtain rise-over, mirror law, graphite theme-shift на комерції, одометр 54 на мосту.
  Копі-пас round-3: тайтли = факти («Кімната більша: 17,34 замість 15,27»).
- **units-17 «Обміряна квартира»** - граматика units-16 на smarts: розмірні лінії dashoffset поверх
  day-05-zahalnyi (coverRect), плани type-27/24 на темному музейному монтажі, місток = лінійка
  підкреслює «Обери свою квартиру.»

## Towns (вул. Замкова, 6 таунхаусів 82 м²)
- **units-11 «Ряд»** - рендер ряду = герой, мігруючий вош позицій, тіки-реле у місток.
- **units-16 «Розміряний двір»** - розмірні лінії dashoffset поверх реальних рендерів.
- **units-20 «Все своє»** - посесивний фільм: один fixed word-slot «Свій/Свої/Своє» = реле через
  4 біти (двір 1,5 сотки -> два поверхи 82 м² -> місце в ряду -> місток «Обери свій таунхаус.»
  свапом на тому ж рядовому фото, без окремого екрана).
