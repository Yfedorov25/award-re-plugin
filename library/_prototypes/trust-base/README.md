# TRUST - база секції (round 1 прийнято 2026-07-02; десктоп; мобільний раунд попереду)

🔴 ТЕМПЛЕЙТ-ФРЕЙМ: це перевикористовувані прототипи-темплейти, НЕ секції обʼєктів.
Всі факти/назви/дати живуть у const DATA нагорі файлу з TEMPLATE CONTRACT-коментарем
(обовʼязкові/опційні поля); re-skin = заміна DATA + асетів, нуль правок розмітки.

## Клас A · повний фактаж (демо-дані: ЖК Агрономічне)
- **t-1 «Шлях до ключів»** (хребет-мандат) - пін-скраб: stage-0 база назавжди, стадії
  clip-wipe знизу вгору (frame-matched, named morph), одометр місяців digit-strip,
  dashoffset-лінія з віхами; пуант = синхронний удар (кромка+«9»+віха+100% в одному кадрі);
  вбудований window.__zeroBlankProbe(). Умови-рядки + міст «Запитати про розтермінування».
- **t-2 «Матеріал у руці»** - persistent-індекс + rigid push-swap ПАРИ (сфера веде, деталь
  з лагом 100ms), FLIP тієї ж ноди на розгортання, Esc/скрім згортає. ASSEMBLY-ВЕТО: якщо
  сайт показує макро-сфери в Architecture, цей варіант не береться (нуль дубля медіа).
- **t-3 «Менше року»** - число-герой: гігантський рил місяців, стадії тихо за цифрою
  (вузькі кросфейди легальні: герой = число).
- **t-4 «Технічний аркуш»** - palette-INVERT білий документ (єдиний легальний світлий =
  жест-інверсія, не тема), self-draw сітки scaleX/scaleY, факти на бейслайнах.
  ⚠️ Демо-реквізити «аркуш 34 · 2025» = приклад; порт вимагає РЕАЛЬНІ реквізити документа.

## Клас B · обмежений фактаж (демо-дані: вул. Замкова; нуль дат/років/девелопера)
- **t-5 «Чесна інвентаризація»** - один тихий full-bleed рендер + факт-CAPS рядки з
  hairline self-draw; рядок «Дати · Назвемо, коли зафіксуємо їх у документах» = чесність-жест.
- **t-6 «Шість із шести»** - антискарсіті: тапи по ряду пишуть той самий статус «вільний»,
  авто-демонстраційний прохід, підсумок «Всі 6 таунів зараз вільні»; тапи НЕ обирають юніт
  (боундарі з Units).

## Закони секції (в усіх)
Підпис чесності «Візуалізація/Документ · стан, дата» одним кутом на всіх медіа + в alt ·
decode-guard Promise.all(decode()) ДО тригерів · progress-driven чиста render(p) ·
reduced-motion/<=820px = повний доказ статично · довіра через ПОКАЗ (кожне число має
медіа-контрапункт), 1 хребет + <=2 підтримки · нуль само-декларацій/бейджів/стоку.
Боундарі: числа розтермінування=Price, статуси-інтерактив=Units, форма=CTA,
таймлайн=ексклюзив Trust.
