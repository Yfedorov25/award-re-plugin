# Theme flow — прогрес теми по секціях

Theme (light/dark/warm tonal register) is not per-section decoration — it is a single arc across the whole page. Pick ONE of the two macro-shapes below, then apply the seam/conversion/render rules. Source models cited from live Vide Infra sites.

## Macro-shapes (pick one per site)

- **BOOK-END DARK→…→DARK** (ERA inventory/art-deco model). Open the hero dark, close CTA+footer dark, oscillate light/dark in between (§01 dark → §02 light manifesto → … → §05 dark lifestyle climax → … → §09 dark close). The footer cross-link ring returns to the §01 baseline so the page LOOPS rather than dead-ends. Use for inventory-rich, structured ЖК with distinct section types.

- **CONTINUOUS WARMTH CRESCENDO** (Springs luxury-poetry model). Start pale cream-gold (preloader→hero, no flip), then run a 3-step saturation/warmth ramp (Wellness→Nature→Place = deepen→hue-shift→peak). The seams are HIDDEN because the whole thing is one continuous surface being re-tinted, not separate themed blocks. Use for atmosphere-depth, mood-led villa brands.

## Transition rules

- **THE ONE HARD FLIP MARKS MOOD→INFORMATION.** Springs spends its single real theme flip exiting the warm gradient triad into the cool structured Map. Reserve a hard tonal reset for the move from emotional act → data/conversion register. Everywhere else, hand off by tonal DEEPEN/LIFT (continuous), not a flip.

- **THEME = THE TRANSITION DEVICE ITSELF** (ERA §02). When the hand-off between two sections should be *felt*, make the theme-flip the seam — fire it via IntersectionObserver at the section boundary — instead of adding a separate transition animation on top.

## Anchor rules

- **QUIETEST THEME AT THE CONVERSION POINT.** Both sites give the form section the stillest, calmest ground (Springs callback = quietest; ERA §08 = decision-clean light). Theme stops oscillating so the user can act.

- **REAL RENDERS FORCE A NEUTRAL-WARM GROUND.** Catalog/residences sections need honest product light — return from any stylized dark/warm mood to neutral-warm for the unit gallery (Springs §06), then re-deepen for the next atmospheric beat.
