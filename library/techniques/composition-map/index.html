Як прийоми складаються в секції springs

Вищий рівень за молекулою. L1-атоми й L2-молекули (16 модулів у techniques/) не живуть поодинці — springs-секція це 3–5 прийомів у стек за граматикою rules/STACKING-GRAMMAR.md: один Ambient + один Entrance + один Interaction, плюс theme-flip на шві. Ця карта показує, який стек будує кожен l-* блок springs.estate — і куди тапнути, щоб побачити прийом живим.

Модель · три часові шари

Легенда стеку

Кожен рядок у картці = один шар граматики. Не «5 незв'язаних анімацій» — а заповнені слоти A+B+C. Клікабельне = наш модуль-прийом (демо телефон+десктоп).

Ambient — завжди-он, поки секція у вью (parallax, drift, tint) Entrance — один раз на inview (reveal, wipe, counter) Interaction — за жестом (swipe, tap, arrows)

Як читати: A/B/C = часовий шар (Ambient / Entrance / Interaction). Один springs-блок = стек із цих шарів, а не один прийом. Що ще НЕ зібрано атомами: наступна фаза після цих 17 модулів — розібрати L2-молекули на переюзні L1-атоми (десятки: clip-канал, stagger, translateY-drift, wash-opacity, odometer-column…), щоб будувати нові award-секції точніше. Springs дав перший повний зріз стеку — інші сайти доповнять граматику. WebGL-біти (wellness / nature / tree) springs робить на Three.js+OGL; ми відтворюємо DOM-нарацію прийому поверх, паритет WebGL-сцени не заявляємо.
