Ядро · послідовність

Екстракційний конвеєр

Кожна сторінка будується детермінованим пайплайном — жодного числа руками. Це фундамент; усе інше стоїть на ньому. Порядок тут — справжня послідовність.

01 — extract

token-extractor

Знімає spec сайту: дерево вузлів × computed-стилі × два вьюпорти. Конфіг-драйв (сайти × секції), самоперевірки.

Прийом: перетин класів архів∩живе + позиційний fallback; lazy data-src форс; nbsp зберігається (керує переносами заголовків).

scripts/token-extractor.mjs
02 — map

scene-map + animation-map

Уся сторінка одним прогоном: снап-драбина, rest-офсети, per-section травели. Плюс криві руху за скрол-фазою.

Прийом: CDP synthesizeScrollGesture(mouse) — єдиний драйвер virtual-scroll; transient-семпли під час lerp; лерп у wall-time.

scripts/scene-map.mjs · animation-map.mjs
03 — generate

choreo-gen

scene + карти → choreo.json (біндінги з матрицями й кривими) + scene.css. Усе генерат.

Прийом: нормалізація осі карти → сторінковий скрол; iEnd екстраполяцією; коліно піна вставкою точки зламу.

scripts/choreo-gen.mjs
04 — render

springs-engine (движок)

wheel-перехват → снап-лерп у нативний scrollTop; вербатим-повтор live-матриць + boot-fix; травели; reveal-латчі.

Прийом: повністю data-driven із choreo → переносний на будь-яку сторінку. Gallery це довів.

library/combos/*/springs-engine.js

Прийоми руху

Це каталог, не послідовність — тому без нумерації. Чіп праворуч кодує стан: доведено пікселем чи межа методу.

Rotated-matrix колаж

доведено

Hero-колаж повернутий ~28° matrix(.883,-.469,.469,.883). Axis-aligned translate не відтворює.

Прийом: зберігати повну матрицю [a,b,c,d,tx,ty], повторювати покадрово.

доведено

Desktop інтро-морф — часовий (авто-фаза ~9.5 с), не функція скролу.

пастка 49

Reveal-латчі

доведено

Reveal = подія тригера + часовий перехід, не функція s. На осілих позах — завжди фінал.

Прийом: rising-o степ по тригеру; clip-вайп степ по геометрії; binary-flip → геометричний reveal.

пастка 23

Ancestor-clip вайпи

доведено

Вайп under-previous = статичний CSS-clip кореня секції; шар піниться повз статичну clip-лінію.

Прийом: ancestorClips (computed clipPath від кореня вгору) → широкий polygon-clip мінус власний травел.

пастка 68
Чесно · межі методу

Що недосяжне no-JS реплікацією

Це не недоробки, а фундаментальні межі — виявлені й доведені тестами, не здогадками.

Splitting-текст

стеля

Live рахує позиції гліфів JS-рантаймом (Splitting.js). Char-span реплікацію побудовано й протестовано → погіршило: бокс уже збігається (720×248), spans пертурбують. Перцептивно 1-в-1 (2–4%).

Вбудоване відео / WebGL springs

зараховано

Vimeo-відео + WebGL-канвас — ассети springs недосяжні. Композиція, геометрія, розташування — 1-в-1; різниця лише в контенті відео → зараховано.

Same-run фазова точність

асимптота

Пікс-точність кожної фази авто-анімації потребує same-run per-pose. Прийом доведено на s=0; scroll-фази — та сама механіка, інші фази.

Стан треку. Движок генералізації доведено пікселем: gallery — 7/7 pass на обох вьюпортах, mobile hero-колаж 32% → ~2%. Конвеєр витримав другу сторінку без переписування — база переносна, наступні сайти йдуть швидше.
