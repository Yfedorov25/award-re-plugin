# ATOM: morph-ribbon — зелено-скляна S-стрічка (WebGL), секція Place (v1)

## СУТЬ
Секція springs «Place / Essence of Contemplation»: на градієнтному фоні (олива-зліва →
темна-хвоя-справа) живе **напівпрозора зелено-скляна S-стрічка** (double-twist), намальована в
WebGL-canvas (`js-nature-canvas` / `webglNature`, спіраль `l-place-webgl__spiral`). По скролу
стрічка спускається/розкручується згори-донизу, звужується, і за нею full-bleed відео бігунів у
лісі проступає ЧЕРЕЗ шов (стрічка ще напівпрозоро присутня поверх відео на переході — crossfade,
не різкий свап). Заголовок «Place» серифом справа, kicker «ESSENCE OF CONTEMPLATION» під ним,
абзац зліва.

## МЕХАНІКИ (з живого відео; наратив голосом Єгора ВІДСУТНІЙ — темп/скраб = гіпотези)
- M1 ФОН: градієнт олива(45%,ліво-низ) → темна хвоя(право-верх), НЕ фейдиться; тонкий teal
  зліва-внизу. Живе завжди.
- M2 СТРІЧКА (WebGL-суть): напівпрозоре зелене скло, форма = вертикальний double-S twist;
  верхній вигин має яскравий жовто-зелений відблиск (край-highlight), низ темніший. Реагує на
  мишу (parallax ±5%, `mouseAnimation` з markup).
- M3 ВХІД/РУХ: по скролу S-хвиля СПУСКАЄТЬСЯ згори-донизу і трохи звужується/розкручується
  (кадри beat-01→03); темп ~2.5s band у записі. (Скраб vs автоплей — ГІПОТЕЗА, бачив лише
  повільний прохід; будуємо scrub-first, per-rAF morph.)
- M4 ТЕКСТ: «Place» (serif, справа, велике) + kicker під ним + абзац зліва. З'являються з
  reveal (`data-reveal`), тексти НЕ морфляться зі стрічкою.
- M5 ПЕРЕХІД (crossfade-шов): full-bleed відео (бігуни в лісі) проступає ЗНИЗУ/через прозорість;
  на переході стрічка ЩЕ присутня напівпрозоро ПОВЕРХ відео (beat-04) → потім чисте відео
  (beat-05) з новим текстом «Breathe in the air…». Це НЕ твердий wipe — crossfade через скло.
- M6: після відео — далі одометр «хвилин до» (3/9/16) — це ІНШІ атоми (odometer/map), не цей.

## ТЕМП (live, запис 21s)
Стрічка+Place ~0–2.5s · crossfade у відео ~2.5–3.5s · відео бігунів ~3.5–8s. (У записі це один
повільний прохід; точний скраб-меппінг = калібрувати оком Єгора.)

## ТЕХ-РЕАЛІЗАЦІЯ (WebGL — єдиний WebGL-атом springs)
Стрічку НЕ можна зняти з DOM/скрінів (canvas = чорна скринька). Будувати shader-стрічку АБО
чесний фолбек: анімований SVG/CSS double-twist зі скляним градієнтом + blur-шари. Для CD:
дозволити Three.js АБО чистий canvas-2D/SVG-морф (CDN). Скло = напівпрозорість + inner glow +
край-highlight. Рух = морф контрольних точок кривої по p (scrub).

## ВІДКРИТІ ПИТАННЯ (закрити наративом/скрол-відео Єгора)
1. Скраб чи автоплей стрічки? (бачив лише повільний прохід). 2. Стрічка входить чи вже на місці
на старті секції? 3. Crossfade у відео — скролом чи авто? 4. Точна к-сть твістів (2 повні S?).
5. Three.js-шейдер vs SVG/CSS-фолбек — що ближче оком.

## TRANSFER-ГЕЙТ
Той самий закон на іншому фасаді: інший колір скла (напр. бурштин), інша к-сть твістів, інший
градієнт-фон — прозоре скло + край-highlight + морф по p + crossfade-шов у медіа працюють.
