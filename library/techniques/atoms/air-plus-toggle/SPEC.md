## СУТЬ (одне речення)
Клік по ✛-чіпу відкриває всередині картки blur-оверлей з описом (0.35s), чіп повертається 45° у ×;
відкрита може бути лише ОДНА картка — відкриття наступної закриває попередню.

## ЧОМУ ЦЕ ПРАЦЮЄ
Картка тримає інтригу (глиф+титул), ✛ обіцяє глибину без переходу на іншу сторінку; «одна відкрита»
тримає фокус і робить грід охайним. Оверлей всередині картки — контекст не втрачається.

## МЕХАНІКИ
- **M1 чіп**: ✛ → обертання 45° у × за 0.3s, transform-only; назад при закритті.
- **M2 оверлей**: rgba(0,0,0,.6) + backdrop-blur(14px) поверх тіла картки; опис fade 0→1 за 0.35s,
  ease .25,.74,.22,.99; великий глиф картки гасне до op .1.
- **M3 закон «клік = тоггл»** (вшито з тортур С31): ЄДИНИЙ тригер відкриття/закриття = click/tap по чіпу.
  hover-open ЗАБОРОНЕНО (hover-open + click-close = конфлікт: мишачий користувач не може закрити).
  Hover дає лише прекурсор (бордер яскравіше, глиф дрейф 4px) — НЕ відкриття.
- **M4 одна відкрита**: відкриття картки B закриває A (обидві анімації симетричні).
- **M5 reduced-motion**: reveal instant, ротація off.

## COUPLING / SCROLL-WINDOW
Чисто інтерактивний (click), скрол не бере участі. Живе в будь-якій секції-гріді.

## ІНВАРІАНТИ ЗАКОНУ
Клік = тоггл (нуль hover-open); 45° ✛→× 0.3s transform-only; опис 0.35s + ease .25,.74,.22,.99;
одна відкрита; оверлей всередині картки (не модалка). Кількість карток, глифи, палітра — фасад.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. Цикл реальною мишею: click-open → click-close → click-open (той самий чіп) — стани сходяться.
2. Відкриття іншої картки закриває попередню (window.__PLUS.open() == новий index).
3. Чіп: matrix ≈ rotate(45deg) у відкритому, 0° у закритому; transform-only.
4. Hover НЕ відкриває (після hover без кліку open() == null).
5. Хук `window.__PLUS = { open: () => index|null }`; 0 errors; reduced-motion = instant.
