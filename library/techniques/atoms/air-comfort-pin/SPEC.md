# ATOM: air-comfort-pin — sticky-титул унизу кадру + glass-картки зигзагом повз нього

> Закон руху, НЕ сніпет. Ролі абстрактні: act (довга секція) / sticky-title (титул-«кінопідпис») /
> glass-cards (колонка карток з reveal-ом на вході у в'юпорт).
> Джерела: AIR `_candidates-about-air/air-comfort-pin.html`, кліп `AIR-REF--sticky-card-parallax.mp4`.
> BUILD: CD batch-1v2 + мій фікс телепорту (С31). Промпт: `CD-RUN-air-batch-1v2/PROMPT-03-comfort-pin.md`.

## СУТЬ (одне речення)
Титул секції прилипає внизу кадру (sticky top 66vh) як кінопідпис, поки повз нього тече колонка
glass-карток, кожна з яких проявляється один раз на вході у в'юпорт; парні картки зсунуті вниз (зигзаг).

## ЧОМУ ЦЕ ПРАЦЮЄ
Нерухомий титул + рухомі картки = паралакс сенсу: тема лишається в кадрі, докази пропливають.
Зигзаг ламає табличність, glass-поверхня тримає картки «над» фоном не перекриваючи його.

## МЕХАНІКИ
- **M1 sticky-титул**: position:sticky, top 66vh — тримається нижньою третиною кадру весь хід секції.
- **M2 glass-картки**: rgba-білий ~.55 + backdrop-blur(20px), 1px hairline-бордер; парні offset translateY(+34px).
- **M3 reveal**: IO threshold .25, one-shot; opacity 0→1 + translateY 24px→offset, 0.7s, ease .25,.74,.22,.99.
- **M4 закон «проскочений = фінал»** (вшито з тортур С31): БУДЬ-яка картка, чий rect уже пройдено
  (bottom<0) АБО частково видима після стрибка (<25% видимості — IO мовчить) → показана миттєво.
  Перевірка не лише на load, а на кожен programmatic jump / дно документа.
- **M5 reduced-motion**: все видиме одразу.

## COUPLING / SCROLL-WINDOW
Тригерний (IO-пороги на вході карток), НЕ scrub: темп reveal-у фіксований 0.7s. Sticky-титул — чистий CSS,
вікно = вся висота секції.

## ІНВАРІАНТИ ЗАКОНУ
Sticky-титул унизу кадру (top ~66vh — «кінопідпис», не хедер); one-shot reveal 0.7s + ease .25,.74,.22,.99;
зигзаг-офсет парних; закон «проскочений = фінал» (включно з під-кейсом дна документа);
transform+opacity only; хорео плавного скролу НЕ ламається фіксом (монотонність збережена).
Кількість карток, glass-параметри, палітра — фасад.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. Sticky: rect титулу стабільний (±1px) при скролі всередині акту.
2. Плавний прохід: кожна картка стартує reveal при ~25% видимості, тривалість ~0.7s.
3. Телепорт у кінець секції: 6/6 карток видимі (включно з частково видимою останньою).
4. Телепорт на дно ДОКУМЕНТА: так само 6/6 (під-кейс, який ловив «мовчазний IO»).
5. Хук `window.__COMFORT = { revealed: () => count }`; 0 errors; reduced-motion = все видиме.
