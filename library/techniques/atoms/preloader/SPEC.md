# ATOM: preloader — шаруватий fade-вихід з trailing wordmark (v1)

## СУТЬ
Прелоадер springs: темно-зелена градієнт-панель full-viewport + примарний серифний wordmark
(~0.35 op) по центру + кастомний спінер (тонка дуга + монограма) праворуч-вгорі. Готовність =
sweep-проява wordmark у повний крем. Вихід = ШАРУВАТИЙ FADE зі зсунутими вікнами: панель тане
першою (сторінка проявляється ПІД нею), wordmark + кільце спінера тануть останніми, повільно.
Жодного wipe/clip/scale у виході. Скрол заблокований до завершення.

## МЕХАНІКИ (FILM 22.41.08, t≈0.9–3.0s; наратив Єгора ВІДСУТНІЙ — гіпотези позначені)
- M1: LOAD-годинник (час, не скрол). Один master-tl; render(p) ставить прогрес напряму.
- M2 APPEAR (p0–0.15): панель з першого кадру (сама не в'їжджає); ghost-wordmark + спінер
  швидкий fade-in.
- M3 HOLD (p0.15–0.55): спінер-дуга обертається (детерміновано = лінійна f(p), ~2 оберти на весь
  таймлайн); панель ледь дихає (op-дрейф ≤3%).
- M4 READY SWEEP (p0.55–0.72): wordmark 0.35→1.0 крем ПОСЛІДОВНОЮ проявою по гліфах
  (gradient-mask travel; напрям зліва-направо — гіпотеза, див. §ВІДКРИТІ).
- M5 PANEL EXIT (p0.72–0.88): панель op 1→0; підкладка одночасно освітлюється з ~35% затемнення;
  дуга спінера тане РАЗОМ з панеллю.
- M6 WORDMARK TRAIL (p0.80–1.00): wordmark + кільце тануть ПОВІЛЬНІШЕ і ПІЗНІШЕ панелі —
  примара висить над уже видимою сторінкою (~1s хвіст на live). Строго: кінець fade wordmark
  ПІЗНІШЕ кінця fade панелі.
- M7: скрол заблокований до p=1; тексти сторінки під панеллю ВЖЕ скомпоновані (не анімуються
  поелементно).

## ТЕМП (live)
Панель з'являється одразу по навігації; hold залежить від мережі (~0.6–1s на плівці); sweep
~0.3–0.4s; вихід панелі ~0.45s; хвіст wordmark ~1–1.2s (повільний ease-out).
