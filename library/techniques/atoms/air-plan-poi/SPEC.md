# ATOM: air-plan-poi — скошена плита-макет з POI-пінами (stagger-поява + hover-акцент)

> Закон руху, НЕ сніпет. Ролі абстрактні: slab (плита-план у перспективі) / pins (квадратні POI-піни) /
> labels (чіп-підписи біля пінів) / ghost-title (гігантський привид-заголовок за плитою).
> Джерела: AIR `_candidates-about-air/air-plan-map-poi.html`, кліпи `AIR-REF--floor-plan-select.mp4` /
> `visual-search-drill`. BUILD: CD batch-1v2 RAW. Промпт: `CD-RUN-air-batch-1v2/PROMPT-04-plan-poi.md`.

## СУТЬ (одне речення)
План-макет лежить «фізичною плитою» під кутом (skewY ~−9°), POI-піни вистрілюють на ньому каскадом 90ms
при першому вході у в'юпорт, hover піна збільшує його (1.12) і показує чіп-підпис.

## ЧОМУ ЦЕ ПРАЦЮЄ
Скіс перетворює плоский план на макет на столі — око вірить в об'єм без 3D. Каскад пінів «розставляє»
об'єкти на очах (наративний акт), hover-чіп дає розвідку без кліку.

## МЕХАНІКИ
- **M1 плита**: aspect ~1440/760, skewY(−9deg), градієнтна поверхня + глибока м'яка тінь; контент плити
  (футпринти, дороги, штрихування) живе В скосі — піни теж (спільна система координат).
- **M2 поява пінів**: перший вхід у в'юпорт → stagger 90ms, scale .6→1 + opacity, 0.4s,
  ease .25,.74,.22,.99; IO .25 one-shot.
- **M3 закон «проскочений = фінал»**: пройдена/проскочена секція → піни видимі миттєво (як у comfort-pin).
- **M4 hover**: scale 1.12, 0.25s, transform-only + чіп-підпис поруч; leave — назад. На тачі hover
  не існує → перший tap = показ чіпа (без click-close конфлікту).
- **M5 reduced-motion**: піни видимі, hover-scale off.

## COUPLING / SCROLL-WINDOW
Тригерний (IO-поріг входу секції), НЕ scrub; hover — інтерактивний шар поверх. Вікно появи одне на життя
сторінки (one-shot).

## ІНВАРІАНТИ ЗАКОНУ
Скіс плити (перспектива без 3D); каскад 90ms + scale .6→1 за 0.4s + ease .25,.74,.22,.99;
hover 1.12 transform-only 0.25s; «проскочений = фінал»; піни в системі координат плити.
Кількість пінів, форма футпринтів, палітра, кут скосу — фасад.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. computed matrix плити відповідає skewY(−9°) (числом).
2. Каскад: старти сусідніх пінів рознесені ~90ms; scale-траєкторія .6→1.
3. Телепорт повз секцію → всі піни у фінальному стані.
4. Hover: matrix ≈ scale(1.12) за ~0.25s, transform-only (нуль layout-props у transition).
5. Хук `window.__PLAN = { pins: () => count, hovered: () => index|null }`; 0 errors; reduced-motion ок.
