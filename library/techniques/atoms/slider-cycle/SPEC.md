# ATOM: slider-cycle — скрол-цикл слайдів у фіксованій картці (springs Nature-слайдер)

> Закон руху, НЕ сніпет. Ролі: stage / slide-card (фіксована маска) / slides[N] / captions[N] / nav.
> Джерела: SOURCE.md (плівка 19.5–28.5s + markup keyframes). Наратив Єгора: PENDING — v1. CD-RUN #3.

## СУТЬ (одне речення)
Велика картка-маска стоїть НЕРУХОМО, а слайди циклять по скролу **wipe-up'ом ВСЕРЕДИНІ маски**
(новий слайд піднімається знизу над попереднім); caption свапається синхронно з межею,
**з overlap виходу/входу**; утримуваний слайд ЖИВЕ повільним зумом.

## МЕХАНІКИ
- **M1 pin**: сцена запінена; ОДИН scrubbed master-timeline; band ≈ 6vh скролу на 3 слайди.
- **M2 маска**: slide-card (велика, ~44vw, зліва; overflow hidden) НЕ рухається весь цикл. Слайди
  абсолютно стековані всередині.
- **M3 цикл**: слайд k+1 заходить wipe-up знизу ВСЕРЕДИНІ маски (clip inset 100%→0% боттом-ап);
  попередній НЕ рухається (його накривають). Ніколи не crossfade.
- **M4 Ken Burns (декларативно з markup!)**: кожен утримуваний слайд зумиться `scale 1.05→1.2`
  ПОВІЛЬНО весь свій hold (вхід на 1.05, при виході вже ~1.2). Слайд живий, не заморожений.
- **M5 caption swap З OVERLAP**: caption k виходить вгору (y→-20% + fade/clip) І caption k+1
  заходить знизу (y 20%→0) У ПЕРЕКРИТТІ (не послідовно) — вікно збігається з M3-межею.
  (Markup: вхід `translateY(20%)→0`, вихід `→-20% + op0`.)
- **M6 nav v2 (виправлено після питання Єгора)**: стрілки = **scroll-jumper** — клік плавно скролить
  (lenis.scrollTo) до центру hold-вікна цільового слайда; хореографію жене ТОЙ САМИЙ scrub. Один годинник:
  скрол і стрілки співіснують бо обидва рухають лише скрол. Лічильник оновлюється від progress.
  (Live-факт: у served HTML стрілок НЕМА — інжектяться JS-ом, як відео; модель scroll-jumper = єдина
  сумісна з їхньою sticky/scrub-архітектурою.)

## BUILD-BINDING

Ken Burns на inner-обгортці слайда (scale, transformOrigin center); caption-пари на тих самих position
з overlap '<0.4'. Ease cubic-bezier(0.25,0.74,0.22,0.99); зум/hold — 'none'. Transform-ownership: GSAP-only.
