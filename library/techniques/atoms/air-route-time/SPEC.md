# ATOM: air-route-time — маршрут-лінія і хвилини від ОДНОГО годинника

> Закон руху, НЕ сніпет. Ролі абстрактні: map-scene (карта/план) / route (SVG-полілінія) /
> counter (гігантське число часу/відстані) / poi-list (тригери).
> Джерела: AIR T-427 (`locmap-engine` + `location--surveyed-route-map`), кліп `AIR-REF--locmap-air-dark.mp4`.
> BUILD: CD batch-1v2 (RAW механіка PASS, фасад A−). Промпт-джерело: `CD-RUN-air-batch-1v2/PROMPT-01-route-time.md`.

## СУТЬ (одне речення)
Клік по POI запускає ОДИН rAF-прогрес, який ОДНОЧАСНО малює SVG-маршрут (dashoffset) і розганяє
гігантське число хвилин 0→ціль — обидва фінішують в ту саму мить; лінія і число = один організм.

## ЧОМУ ЦЕ ПРАЦЮЄ
Синхронний фініш лінії і числа створює відчуття «виміряного» маршруту — карта не декорація, а прилад.
Розділені анімації (лінія окремо, число окремо) миттєво читаються як фейк.

## МЕХАНІКИ
- **M1 один годинник**: `t = clock(1.4s)`, ease cubic-bezier(.25,.74,.22,.99) застосований до t;
  route.dashoffset = len·(1−e(t)); counter = round(e(t)·target). ЖОДНИХ двох таймерів.
- **M2 малювання маршруту**: stroke-dasharray/dashoffset на SVG-полілінії від точки-бази до POI.
- **M3 зміна POI**: попередній маршрут fade-out 0.3s ПОКИ новий малюється (перекриття, не послідовність);
  активний POI підсвічується акцентом.
- **M4 підпис**: under-line формату «MIN ON FOOT · X.X KM» оновлюється разом з фінішем.
- **M5 reduced-motion**: instant (лінія і число одразу фінальні).

## COUPLING / SCROLL-WINDOW
Тригерний по кліку (НЕ scrub): темп фіксований 1.4s. Скрол не бере участі — атом конверсійного класу
(локація/маршрути), живе всередині пінової або статичної секції.

## ІНВАРІАНТИ ЗАКОНУ
Один rAF-прогрес на пару лінія+число (num == round(ease(p)·target) у БУДЬ-ЯКИЙ момент);
синхронний фініш; 1.4s + ease .25,.74,.22,.99; fade-out попереднього 0.3s під час нового;
transform/stroke-only (нуль layout). Кількість POI, стиль карти, палітра — параметри фасаду.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. Семпл у mid-анімації: num == round(ease(p)·target) (одногодинниковість доведена числом).
2. Лінія і число фінішують в один кадр (Δ ≤ 1 rAF).
3. Клік по іншому POI під час анімації: старий маршрут fade, новий малюється, лічильник перезапущено.
4. Хук `window.__ROUTE = { active: () => index, progress: () => 0..1 }`.
5. 0 console-errors; reduced-motion = instant.
