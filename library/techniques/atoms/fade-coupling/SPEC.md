# ATOM: fade-coupling — opacity, зчеплена зі скролом (~40 інстансів springs)

## СУТЬ
Прозорість елемента = функція його позиції у в'юпорті (scrub, реверсно): fade-in на вході у вікно,
fade-out на виході (часто в парі з translateY ±20% — тоді це композит з parallax-drift).

## МЕХАНІКИ (декларативно з markup)
- M1: driver = вікно елемента, scrub, `ease:none`.
- M2: типові пари: `opacity 0 + translateY(20%) → 1 + 0` (вхід) · `1 → 0 + translateY(-20%)` (вихід угору).
- M3: fade НІКОЛИ не застосовується до full-bleed медіа-свапів (там тільки wipe — закон сайту);
  fade = для текстів/капшенів/дрібних елементів.

## TRANSFER-ГЕЙТ
Тексти на dummy-фасаді в'їжджають з прозорості знизу і тануть угору при виході, реверсно.
