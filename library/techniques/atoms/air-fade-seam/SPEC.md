# ATOM: air-fade-seam — шов світла секція → темна одним фільмом

> Закон руху, НЕ сніпет. Ролі абстрактні: exiting-section (світла) / next-section (будь-який темний колір).
> Джерело: AIR /about `section-fade-overlay` (знято з живого DOM 2026-07-06). Пазл: air-seam-1.
> ✅ TRANSFER-ГЕЙТ (числовий) ПРОЙДЕНО 2026-07-16: крем→глибока зелень (не чорна!), serif-фасад — закони M2/M3 звірені числами (playwright PASS). APPROVE-око Єгора: ⬜ попереду.

## СУТЬ (одне речення)
Внизу світлої секції лежить панель кольору НАСТУПНОЇ секції (60svh), і її opacity росте `0→0.5` пропорційно прогресу виходу секції з екрана — межа між секціями зникає, скрол читається як монтаж, не перемикання слайдів.

## ЧОМУ ЦЕ ПРАЦЮЄ
Око читає поступове затемнення низу як наближення наступної сцени (кіношний dip-to-color розтягнутий по скролу). Панель, а не gradient: рівний колір без бандингу, дешевий композит (лише opacity).

## МЕХАНІКИ
- **M1 панель**: `::after` секції, `position:absolute; bottom:0; height:60svh`, колір = фон наступної секції, `pointer-events:none`.
- **M2 закон прогресу**: `p = 1 − clamp01(rect.bottom / (vh + h·0.6))` — 0 доки низ секції нижче в'юпорту, 1 коли низ дійшов верху екрана (h = висота секції).
- **M3 закон прозорості**: `opacity = p · 0.5` (стеля 0.5 — секція темніє, але не вмирає до фізичної межі).
- **M4 драйвер**: rAF-тикер по scroll/resize (passive), запис через CSS-змінну `--seam-p` (toFixed(3)).

## COUPLING / SCROLL-WINDOW
Scrub (прямий coupling до скролу, без інерції/твінів). Вікно = вихід секції: від «низ секції на низі екрана» до «низ секції у верху екрана» (+40% запасу через h·0.6 у знаменнику).

## ІНВАРІАНТИ ЗАКОНУ
Висота панелі 60svh; стеля opacity 0.5; формула p (M2); лише opacity (жодних transform/градієнтів). Колір панелі = колір наступної секції (НЕ обов'язково чорний) — це параметр ролі, не фасаду.
⚠️ Панель МУСИТЬ бути full-bleed: клас шва вішати на ПОВНОШИРИННУ секцію-обгортку, не на контент-колонку з max-width (інакше читається як «сірий прямокутник з полями», не шов — спіймано скріншот-оком у transfer-тесті, виправлено).
