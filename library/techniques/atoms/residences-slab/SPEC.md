  Hover → розкривається ВГОРУ, показує статистику (напр. «138 / up to 3.1 m»).
- **M4 ПОСТІЙНІСТЬ:** контейнер ОДИН на весь band — з'являється з першим рендером і НЕ зникає;
  на переходах КРОСФЕЙДИТЬСЯ ЛИШЕ ТЕКСТ усередині (Flats → Townhouses → Penthouses + статистика).

- M6 label top-left: swap з overlap (вихід вгору + вхід знизу).
