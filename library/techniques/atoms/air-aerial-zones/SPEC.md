# ATOM: air-aerial-zones — пін над аерофото: кольорові зони + хв-картки каскадом

> Закон руху, НЕ сніпет. Ролі абстрактні: aerial (full-bleed сцена-місце) / zones (напівпрозорі
> кольорові плями-категорії) / minute-cards (картки «місце · N MIN»).
> Джерела: AIR T-121+T-210, кліп `AIR-REF--aerial-journey.mp4`.
> BUILD: CD batch-1v2 (механіка PASS; фасад C+ — боке замість місця). Промпт: `CD-RUN-air-batch-1v2/PROMPT-02-aerial-zones.md`.
> 🔴 ТЗ-v3 п.2: фото-залежний атом — аерофото ГЕНЕРУЄТЬСЯ (Higgsfield) до промпта, НЕ малюється CSS.

## СУТЬ (одне речення)
Секція 250vh пінить аерофото на весь екран; на p≥0.45 поверх нього проявляються кольорові зони-категорії
(0→0.55 op), слідом каскадом 120ms виїжджають хвилинні картки; реверс скролу знімає все у зворотному порядку.

## ЧОМУ ЦЕ ПРАЦЮЄ
Аерофото = довіра («ось реальне місце»), зони = семантичний шар поверх реальності, хвилини = конверсійний
аргумент. Порядок проявлення (місце → категорії → цифри) веде око від контексту до вигоди.

## МЕХАНІКИ
- **M1 пін**: секція 250vh, сцена position:sticky 100vh; p = scrolled/(H−vh).
- **M2 зони**: p ≥ 0.45 → зони opacity 0→0.55, 0.6s, ease .25,.74,.22,.99 (органічні radial-плями, не прямокутники).
- **M3 картки**: після зон — каскад карток «PLACE · N MIN», stagger 120ms, translateY 16px→0 + opacity, 0.5s кожна.
- **M4 реверс**: p < 0.45 → картки ховаються, зони fade-out (стан монотонно слідує за p).
- **M5 reduced-motion**: static, все видиме.

## COUPLING / SCROLL-WINDOW
Пороговий усередині scrub-піна: пін тримає сцену весь хід 250vh, але зони/картки тригеряться порогом
p=0.45 з фіксованим темпом (0.6s/0.5s), НЕ scrub-ом. Вікно карток одразу за зонами (без діри).

## ІНВАРІАНТИ ЗАКОНУ
Пін 100vh усередині ≥2.5vh треку; поріг 0.45; op зон 0.55; каскад 120ms; ease .25,.74,.22,.99;
реверс симетричний (нижче порога все знято); transform+opacity only. Кількість зон/карток,
кольори категорій, конкретне місце — параметри фасаду.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. Пін тримається весь трек (rect сцени стабільний при 0<p<1).
2. Зони off при p=0.40, on при p=0.50 (поріг числом); реверс — симетрично.
3. Каскад карток: старти сусідніх карток рознесені на ~120ms.
4. Телепорт за секцію (jump до низу): зони+картки у фінальному стані (не «мовчазний» IO).
5. Хук `window.__AERIAL = { p: () => progress, zonesOn: () => bool }`; 0 errors; reduced-motion = static.
