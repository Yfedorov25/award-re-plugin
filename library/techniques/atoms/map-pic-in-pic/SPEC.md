# ATOM: map-pic-in-pic — панель-слайсер у живій сцені (v2, закон з live-кадрів 17.20.46)

## СУТЬ
Full-bleed сцена ЖИВЕ весь band (повільний зум ease:none, ніколи не завмирає); крем-панель з
картою wipe-up слайсером заходить у сцену і тримає довгий hold. Вихід сцени = атом wipe-up (не цей).

## МЕХАНІКИ
- M1 pin (+=400%), ОДИН тригер, ОДИН master-tl, scrub.
- M2 фон: scale 1.05→1.15 лінійно по ВСЬОМУ band (0→1) — «сцена жива».
- M3 панель: ВПРИТУЛ до правого краю (bleeds off-right), зелена смуга зліва ~12vw; top ~14vh.
  Вхід = clip inset(100% top)→0 (межа знизу-вгору зі скролом) + y 60→0 settle; вікно p0.30–0.55.
- M4 caption їде РАЗОМ з панеллю (те саме вікно, overlap '<0.3', рядки з overflow-масок).
- M5 маркери ×5 стаггером у кінці вікна панелі (scale .6→1 + fade); drop-бейдж осідає ОСТАННІМ
  (scale .8→1, back-ease) до ~p0.62.
- M6 hold p0.62–1.00: панель нерухома, фон живе далі. НІЧОГО не виходить.
