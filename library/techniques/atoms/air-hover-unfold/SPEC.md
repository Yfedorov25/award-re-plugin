# ATOM: air-hover-unfold (B4) — hover-розгортання картки clip+translate без зсуву лейауту

> Закон руху, НЕ сніпет. Ролі абстрактні: card (елемент списку/гріду) / fold (прихований контент:
> опис, метадані, CTA) / media (опційний кадр, що доводиться hover-ом).
> Джерела: AIR картки переваг/інвест-блоку (T-4xx сім'я). BUILD: CD batch-2 (RAW 5/5 гейтів, 0 фіксів).
> Конверсійний клас (списки офісів, переваги, інвест-картки).

## СУТЬ (одне речення)
Hover розгортає прихований шар картки жестом clip+translate (101%→0) за 0.45s — контент
«виїжджає з-під згину», при цьому лейаут сусідів не рухається ні на піксель (нуль-CLS).

## ЧОМУ ЦЕ ПРАЦЮЄ
Розгортання винагороджує намір: картка відповідає на курсор фізичним жестом (розгин, не fade).
Нуль-CLS критичний — якщо сусідні картки смикаються, грід читається як зламаний.

## МЕХАНІКИ
- **M1 жест**: fold-шар clip-path/translate 101%→0, 0.45s, ease сигнатурний; reverse при leave.
- **M2 нуль-CLS**: fold живе в absolute/overlay всередині картки — розміри картки НЕ змінюються.
- **M3 тач=тоггл** 🔴: на тач-пристроях перший tap = відкрити, повторний = закрити (hover-open
  на тачі заборонено — закон A11 plus-toggle, звірено).
- **M4 focus**: клавіатурний focus = hover (доступність, гейт).
- **M5 reduced-motion**: instant show/hide без travel.

## COUPLING / SCROLL-WINDOW
Тригерний по hover/focus/tap (НЕ scrub). Темп фіксований 0.45s. Живе всередині будь-якої секції.

## ІНВАРІАНТИ ЗАКОНУ
101%→0 (повний старт за згином, без «визирання»); 0.45s обидва напрямки; нуль-CLS доведений
числами; тач=тоггл; transform/clip-only (нуль layout-props). Контент fold-а, грід, палітра — фасад.

## TRANSFER-ГЕЙТ (acceptance, ганяти числами)
1. Rect-и всіх СУСІДНІХ карток до/під час/після hover ідентичні (нуль-CLS).
2. Мід-анімація: fold у проміжному стані clip/translate (не instant).
3. focus → той самий стан, що hover; blur → згорнуто.
4. Емуляція тач: tap відкриває, другий tap закриває, hover-події ігноруються.
5. 0 console-errors; reduced-motion = instant.
