# Еталон медіа swim-картки (вказівник, S56)

Окремого Vimeo-кліпу для swim НЕ існує. У live-HTML /infrastructure лише дві
Vimeo-секції: 2.video (wellness) і 7.forest. Монтажні склейки, які S55 виміряв
у картці swim (бігун → руки → плавчиня → вода), збігаються зі сценами кліпу
**`../../amenities-wellness/reference/wellness-orig-mobile.mp4`**
(Vimeo 1086359033, 1080x1920, 30fps, 18.1с):

- сцени кліпу: плавчиня 0-6с (мʼяка склейка на воду ~3с) · ноги-тренажер 6-9с ·
  руки-медитація 9-10.9с · (10.9-12.1с) · бігун 12.1-15.1с · масаж 15.1-18с;
- порядок з запису картки відтворюється при старті з середини лупу
  (бігун → масаж-«руки» → луп → плавчиня → вода);
- ⚠️ точні дельти склейок різняться з виміром S55 (3.0/2.9/3.0с проти 4/2/4с на
  12fps-сітці малої картки). Це в межах точності того виміру, але НЕ доведено, що
  картка грає саме цей файл, а не окремий портретний монтаж. ЗВІРИТИ при добиванні
  swim: кадри картки з live-запису проти кадрів цього кліпу на тих самих сценах.

Правова межа: еталон лише для ока і вимірників, у білд/борд НІКОЛИ
(гейт scripts/reference-guard.mjs).
