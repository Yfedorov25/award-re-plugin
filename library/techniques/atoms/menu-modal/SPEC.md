1. Анімація ВХОДУ оверлея (wipe-up панелі / fade / slide?) — на кадрах дрібно не видно.
2. Стаггер пунктів на відкритті — є/нема? 3. Закриття = точний реверс? 4. Клік по пункту =
навігація (в live так) чи в демо лишити превʼю-свап. 5. Чи картинка свапається на HOVER чи лише
на ACTIVE (в live курсор наводиться і картинка вже інша — схоже hover).
