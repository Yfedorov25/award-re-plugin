# ATOM: interiors-cycle — вхід-заставка + пін-цикл кімнат у лівій масці з thumbnail-рейкою (v1)

## СУТЬ
Секція interiors springs: (1) full-bleed ПРИГЛУШЕНА кімната-заставка з display-словом і абзацом;
(2) спліт-композиція накриває її wipe-up'ом (закон cover-scroll); (3) пін-цикл: 5 кімнат
свапаються wipe-ом ЗНИЗУ-ВГОРУ всередині НЕРУХОМОЇ лівої маски (~50vw, повна висота), крем-панель
справа постійна, вертикальна thumbnail-рейка (5 мініатюр) веде активний стан синхронно зі свапом.

## МЕХАНІКИ (FILM 22.41.08, кадри 40.5–48.5s; наратив Єгора ВІДСУТНІЙ — гіпотези позначені)
- M1: pin band, ОДИН тригер, ОДИН master-tl (scrub).
- M2 ВХІД: full-bleed кімната ПРИГЛУШЕНА (низька насиченість/сірувата — кадр i12); display-слово
  serif з'являється по центру-справа + letterspaced sub + абзац знизу-зліва (на зображенні, читабельний).
- M3 ПЕРЕХІД: спліт-лист (фото-маска зліва + крем-панель справа + рейка) накриває заставку
  ЗНИЗУ-ВГОРУ як ОДИН шар з твердим швом (кадр i14) — той самий wipe-up закон.
- M4 ЦИКЛ: нова кімната wipe-up ЗНИЗУ-ВГОРУ всередині нерухомої лівої маски (кадр i22: межа
  посеред маски, зверху стара, знизу нова). Свап = скраб (межа їде зі скролом). Порядок з live:
  living → study/полиці → bedroom → bathroom (+перша = 5 станів рейки).
- M5 РЕЙКА: 5 вертикальних мініатюр на крем-панелі справа; активна = рамка + повна opacity,
  неактивні пригашені; активний стан перемикається РАЗОМ зі свапом кімнати (кадри i17→i20→i22→i24).
- M6 (гіпотеза за законом slider-cycle §M6, на live НЕ зафіксовано кліку): мініатюра клікабельна =
  scroll-jumper (lenis.scrollTo у band кімнати — той самий годинник, не окремий твін).
- M7: hold-и між свапами з ледь-зумом утримуваної кімнати (Ken Burns, ease:none) — гіпотеза за
  законом slider-cycle §M4; на 2fps-кадрах зум не доведений.
- M8: текст крем-панелі ПОСТІЙНИЙ весь цикл (не свапається — відмінність від residences-slab).
- ВИХІД (footer накриває) = атом wipe-up, НЕ цей.
