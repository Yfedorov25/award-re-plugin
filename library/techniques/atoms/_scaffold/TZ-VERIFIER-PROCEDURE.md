# ПРОЦЕДУРА НЕЗАЛЕЖНОГО ТЗ-ВЕРИФІКАТОРА (план ради S47, крок 4; ПРОБНИЙ статус 3-5 атомів)

> Статус: ПРОБНИЙ — sunset за метрикою після 3-5 атомів (рішення Єгора, рекомендація судді).
> Мета: розірвати correlated blindness — валідний ЛИШЕ diff незалежних ЧИСЕЛ,
> НЕ рецензія чужого тексту.

## ЗАЛІЗНІ ПРАВИЛА

1. **КАРАНТИН**: верифікатор = ОКРЕМИЙ agent-запуск (нова сесія / Task-агент без контексту
   автора). Йому ЗАБОРОНЕНО читати CHOREO.md, SPEC.md, claims автора — до кроку 4.
2. **ВЛАСНІ ЧИСЛА ДО ЧУЖИХ**: спочатку власний прогін вимірів, потім знайомство з таблицею
   автора. CONFIRMED без власного числа = невалідний формат (вшито в схему TZ-VERDICT).
3. **Обсяг lite**: трек-числа + 10-20 вирішальних кадрів. НЕ «сотні кадрів» — числа
   диференціюють механіки, око — ні (вердикт ради).

## ВХІД (дозволений верифікатору)

- `reference/<name>-live.mp4` (live-відео)
- `reference/zones.json` (зони; можна ЗАПЕРЕЧИТИ зони — це теж diff)
- `reference/*.zonetrack.json` — МОЖНА перегенерувати самому: `node scripts/zone-track.mjs --atom <id>`
- порожня анкета: `TZ-CLAIMS-BLANK.md` (цей scaffold)

## КРОКИ

1. Запусти zone-track сам (або звір sha наявного: videoSha/zonesSha мусять збігатись з файлами).
2. Витягни 10-20 вирішальних кадрів навколо вікон руху (`ffmpeg -ss ... -frames:v 1`).
3. Заповни ВЛАСНУ CLAIMS-таблицю (формат `CLAIMS-template.md`): зона × вікно → вердикт
   із закритого словника + src=число. Для кожного переходу ≥2 гіпотези + число-вбивця.
4. ТІЛЬКИ ТЕПЕР відкрий CHOREO.md автора. Запусти машинний diff:
   `node scripts/claims-diff.mjs --atom <id> --author CHOREO.md --verifier <твоя-таблиця.md>`
   → `TZ-VERDICT.json` {sameClass, diffs[], pass}.
5. БУДЬ-ЯКИЙ diff (клас / вердикт клітинки / відсутнє покриття вікна) = борд-блокер Єгору.
   НЕ «узгодити між собою» — розбіжність вирішує ОКО Єгора, не переговори агентів.

## ВИХІД

`atoms/<id>/TZ-VERDICT.json`:
```json
{ "tool": "claims-diff.mjs", "atomId": "...", "authorSession": "<id>", "verifierSession": "<id>",
  "sameClass": true, "diffs": [], "pass": true, "verifierNumbersFirst": true, "ts": "..." }
```
Гейт (verdict-gate у plugin): без TZ-VERDICT.json з pass:true (0 diffs) variants/*.html
не записується; session-id автора ≠ session-id верифікатора (карантин перевіряється).

## МЕТРИКА SUNSET (після 3-5 атомів)

- скільки diffs зловив верифікатор яких НЕ зловив zone-track/structure-parity?
- 0 унікальних знахідок за 3-5 атомів → sunset (машинних вимірів досить);
- є унікальні → лишити, класи знахідок вшити в детектори (ratchet).
