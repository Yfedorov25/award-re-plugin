## СУТЬ
Бежевий ґрунт накриває темний шар; зустрічна пара плит відкривається НАЗУСТРІЧ (знизу-вгору +
ЗВЕРХУ-ВНИЗ); абзац МІЖ плитами; плити виходять ЗА шар (ковтаються обгортками); велика пара
staggered chase; діагональний display-каскад на чистому ґрунті.

## МЕХАНІКИ (v2 + фікси за фідбеком Єгора S37)
- M1 pin (+=700%), ОДИН тригер, ОДИН master-tl, scrub.
- M2 всі clip-межі ease:none (лінійні зі скролом); вікна ПЕРЕКРИТІ: beige 0–.16, p1 .02–.20,
  p2 .07–.25 — дві межі ЯВНО одночасно (перевірка @p.13).
- M3 «плити їдуть»: обгортки y-дрейф до нейтралі ПІД ЧАС входу (10vh/−8vh→0), статичні до exit.
- M4 абзац МІЖ плитами (top 40vh, центр −6vw), піднімається з рядкових масок .24–.33;
  центрується (x→0) під час exit-behind.
- M5 EXIT-BEHIND: обгортки static overflow:hidden; НА ВИХОДІ анімується ЛИШЕ inner-плита
  (права вгору, ліва вниз) — край обгортки ковтає; на жодному p ніщо не пливе поверх бежевого.
- M6 велика пара: b1 .56–.69 знизу-вгору; b2 стартує на ~40% b1 (.612) — chase.
- M7 каскад: 3 рядки по діагоналі з власних масок (yPercent 110→0 + autoAlpha), .74–.875,
  на ЧИСТОМУ бежевому (не перетинає плити — гейт-точка @p.90). Приховані рядки autoAlpha:0.
- M8 hold до 1.0; вихід = інший атом.
