# ATOM: clip-reveal — скраб-відкриття картинки clip-полігоном (~60 інстансів springs)

## СУТЬ
Картинка в потоці відкривається wipe-up'ом (clip-path polygon/inset 100%→0% знизу) СКРАБОМ по своєму
вікну входу у в'юпорт + одночасний scale-settle 1.2→1.0 всередині маски. НЕ triggered-твін — межа
йде рівно зі скролом (реверсна).

## МЕХАНІКИ (декларативно з markup)
- M1: driver = вікно елемента (як parallax-drift M1), scrub.
- M2: `clip-path: polygon(0% 100%,100% 100%,100% 100%,0% 100%) → повний` (wipe-up знизу; сколапсований
  стан = усі точки на нижньому краї) — ТОЙ САМИЙ полігон-закон що в odometer item-ах.
- M3: inner-media `scale 1.2→1.0` тим самим вікном (transform-ownership: обгортка = clip, inner = scale).
- M4: вікно반 = приблизно [елемент торкнувся низу в'юпорта .. елемент на 60% висоти] — короткий, reveal
  завершується поки елемент ще в нижній половині екрана.

## TRANSFER-ГЕЙТ
Кілька картинок на dummy-фасаді відкриваються скрабом при скролі вниз І закриваються при скролі вгору.
