## ЗАКОН РУХУ (T-409) — доведено кадром
1. **Тягнеш PRICE правий хендл** 706 815 000 → 231 000 000 → **FOUND 69 → 60** (лічильник живо перераховується).
2. Список **ре-рендериться чистим swap** (старі картки гаснуть → нові заходять; НІКОЛИ overlap-cross-fade —
   закон caption-swap [[cd-run-folder-convention]]). Число FOUND анімується count-down (не миттєвий стрибок).
3. Тоглери чіпів / сортування `ASCENDING PRICE ▾` → той самий swap-ре-рендер.
4. `CLEAR` → усі фільтри в дефолт, FOUND назад, список повний.
5. `LIST/GRID` → перемикач layout (рядки ↔ картки), контент той самий.
6. Hover рядка/картки → підсвітка (трохи темніший фон). ♥ клік → toggle favourite (заповнений/контур).
7. Drill: клік по картці → план офісу + RESERVE (окремий стан, поза цим атомом — молекула M-9).

- Лічильник FOUND = f(активні фільтри), рахується з РЕАЛЬНОГО набору, не хардкод.
