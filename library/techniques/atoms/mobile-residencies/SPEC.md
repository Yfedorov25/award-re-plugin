# ATOM: mobile-residencies — titled photo-stack (v1) [MOBILE 390×844]

## СУТЬ
Повторюваний організм springs-mobile: **вертикальний стек full-width фото-плиток, вирівняних
ПРАВОРУЧ** (лишають ~28% зеленого поля зліва), + **великий серифний титул напівпрозорий cream,
вертикально ЦЕНТРОВАНИЙ, вирівняний ЗЛІВА, лежить ПОЗАДУ плиток**. По скролу плитки їдуть угору повз
титул, який тримається (pin-подібно), і **перекривають його праву частину** (тому в живому
«Residenc·es» обрізане плиткою). Титул = назва секції (Residencies / Architecture / Infrastructure —
той самий закон, різний текст). Фон = глибокий зелений springs.

## МЕХАНІКИ (з живих кадрів)
- M1 СТЕК ПЛИТОК: 2 full-width фото-плитки (басейн/wellness зверху + residence-інтерʼєр знизу),
  вирівняні праворуч, ширина ~72% екрана (зелене поле ~28% зліва), між ними вузький зазор ~8px.
  Плитки прямокутні вертикальні (~portrait 3:4).
- M2 ТИТУЛ-ПОЗАДУ: великий серифний «Residencies» (2 слова в живому одним рядком, cream ~0.5 opacity),
  вертикально центрований, вирівняний зліва (x починається від краю зеленого поля), z ПІД плитками.
- M3 СКРОЛ = PIN-STACK: по скролу плитки транслюються угору (parallax швидше за титул), титул
  тримається довше в центрі (pin-подібно) → плитка наповзає й перекриває праву половину слова.
  Коли секція виходить — титул спливає вгору разом зі стеком. Наступна секція = той самий закон,
  інший титул + інші плитки (crossfade/стик між секціями — за [[mobile-mechanic-when-differ]]:
  визначальний рух той самий, зміна лише медіа).
- M4 ВХІД (гіпотеза — кадри вже в скролі): плитки заходять знизу з легким y+fade коли секція входить
  у viewport; титул fade-in по центру.

## ІНТЕРАКТИВ / СКРОЛ (390×844)
Скрол-керована секція (не тап). Hooks: `window.render(p)` clamp 0..1 (p = прогрес секції: плитки
угору, титул pin→release) + `window.__ATOM_OK__`. Lenis. Сторінка ≥170vh (щоб стек прокрутився).
🔴 pinned-scroll+crossfade за пам'яттю [[mobile-is-pinned-scroll]] — mobile = pin+scroll, не auto.
