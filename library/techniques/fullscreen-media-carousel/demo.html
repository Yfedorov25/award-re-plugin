Подивись: edge-to-edge карусель рендерів резиденції — слайд заповнює ВЕСЬ в'юпорт (без карткового chrome), гортається по одному повному екрану за раз; слайд може бути img або video.

Один push-slide механік (track translateX(-index*100%)); різниця платформ — ІНТЕРАКЦІЯ (ввід), не драйвер: десктоп = ‹ › стрілки (клік/клавіші), мобайл = свайп пальцем. Springs mobile — свайпний full-bleed слайдер; desktop — arrow-paged. БЕЗ auto-advance (карусель не гортає сама).
