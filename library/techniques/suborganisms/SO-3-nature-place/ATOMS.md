## Метод (для наступних секцій — ЗАКОН)
1. Розбивати ЖИВЕ відео на 7fps+ (≥5× густіше 0.8с).
2. **Детектор сигнатур per-frame** (lum по зонах + колір-маркери) → ТОЧНІ межі атомів (кадр→scroll-частка).
   НЕ вгадувати тайминги. Таблиця істини ПЕРШОЮ.
3. **track-engine:** кожен атом = незалежний трек `{el, prop, from, to, p0, p1, ease}`, всі читають ОДИН p.
   Одночасність виникає САМА коли вікна перекриваються (з таблиці). GPU-only transform/opacity.
4. Будувати треки по одному (кожен ізольовано плавний), тоді скласти в масив = компонування безкоштовне.
