# invest-card-reveal: темна картка переваги · глибина на дотик, на телефоні - на свайп

Атом інвест-секції AIR (T-430) - тієї, яку власник назвав топ: «максимально
круто, лаконічно, стримано і глибоко». Картка у спокої тримає лише індекс і
короткий версальний титул унизу; повний текст ЗАХОВАНИЙ під титулом. Ховер
або клавіатурний фокус піднімає титул на виміряний lift (висота тіла + gapPx,
знято один раз у measure() після fonts.ready - D6) і розкриває текст
clip-path-ом зверху-вниз з волоском-лінією scaleX. Розмір картки незмінний:
грід заморожений, bbox-перетин із сусідами нуль (C28, проба на СЕРЕДНІЙ
картці ряду). Закриття чекає, поки картка і не hovered, і не focused.

На ≤768px діє граматика з реального телефонного запису AIR (T-M18): ховер
ВБИТИЙ, і замість нього НЕ тап - картки стають горизонтальною scroll-snap
стрічкою морозного скла поверх темного архітектурного макро-фото
(host-розмітка кладе <img> під трек + щільніший tint, ніколи blend - D2).
Титул зверху, повний текст одразу знизу, сусідня картка визирає з-за краю
як свайп-кью. Нуль слухачів, нуль GSAP: стрічка = нативний снап-скрол.
Без JS / під reduced-motion картка = статична правда: повний текст видимий
одразу, нуль слухачів, нуль руху.

## Розмітка + виклик
```html
<!-- host-обгортка: на мобайлі під трек лягає СТАТИЧНЕ темне макро-фото -->
<div class="stage">
  <img class="stage-bg" src="renders/macro-roof.webp" alt="" aria-hidden="true">
  <div class="stage-tint" aria-hidden="true"></div>
  <div class="grid" data-icr>
    <article data-icr-card>
      <span data-icr-index>01</span>
      <h3 data-icr-title>Оплата</h3>
      <p data-icr-body>Платите всю суму одразу та отримуєте знижку.</p>
    </article>
    <!-- ... 3-5 карток -->
  </div>
</div>
```
```js
const icr = InvestCardReveal.create('[data-icr]', { ease: 'air', duration: 0.55 });
await icr.ready;          // desktop: fonts.ready + measure; mobile: стрічка зібрана
// desktop вручну: icr.open(1); icr.close(1); icr.cards[1].lift
// mobile: icr.track = снап-трек (текст завжди відкритий, open/close - no-op)
```

## Доведено (lab, headless-цифри)
Чотири картки чесного регістру (ЕТ-29: Статус / Двір / Рендери / Дати) між
full-bleed рендер-секціями (C11); на мобайлі стрічка їде поверх
renders/macro-pergola.webp під tint 0.55. Виміряно 1440x900: закрита
правда на всіх 4 картках; драйв середньої - opacity 0.315 → 0.892 → 1.0 на
семплах 120/300/800ms, титул піднявся на 78px = виміряний lift 78px,
перетин із сусідами 0 px², тіло всередині картки; mouseleave закриває;
focus відкриває / blur закриває; 0 console errors. 390x844 (T-M18):
стрічка зібрана, текст відкритий на всіх картках, драйв scrollLeft 200 →
трек реально на 191px, снап «x mandatory» на кожній картці, картка = 31%
трека (сусідки видно з обох боків), жоден текст не обрізаний, сторінка без
x-скролу, морозне скло blur(14px) над завантаженим макро, сторінка 2.31
екрана, максимальний проміжок 0.12 екрана, текст-ректи від 23.4px.
Ті самі пакети зелені й на 1280x720. Числа звіряються з window.__PROBE.
