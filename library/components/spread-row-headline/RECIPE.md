# spread-row-headline: act-подія · слово-речення роз'їжджається на весь екран

Системний act-розділювач AIR. Заголовок 2-4 коротких слова живе в ряду flex
space-between (spread-стан = CSS-правда, працює без JS і в reduced-motion).
Прогрес — РЕАЛЬНИЙ прохід секції-пасу крізь в'юпорт (C21): атом знаходить
`[data-srh-section]` (~200vh, ряд по центру) і скрабить її
`'top top' → 'bottom bottom'`, тобто `p=(-rect.top)/(rect.height-vh)`.
Ряд слів разом із kicker живе в CSS sticky-обгортці 100vh усередині секції
(v3): він тримається вертикально по центру в'юпорта ПРОТЯГОМ УСЬОГО проходу
1800px — слова супроводжують весь акт, жодної порожньої кольорової смуги
(C22-порожнеча, дефект v2). Зібране слово-речення (зазори 0.14em, майже
впритул) розлітається на сотні пікселів до країв (дельта >40% ширини
в'юпорта — машинна проба) і стає архітектурною лінією ≥90% екрана.
Кожне слово у власному зсунутому прогрес-вікні (stagger), house ease живе
всередині вікна, трек лишається 1:1 до скролбара. Тільки `transform:
translateX`; вертикальне утримання — CSS sticky, НЕ GSAP pin (owns_pin
false, пін-бюджет цілий; предки sticky без overflow-x:hidden, К1.7).

Фізика амплітуди: довгі слова з'їдають розмах. Для act-події бери ~12-14
літер сумарно на 3 слова — тоді кластер ≤55% ряду і подія читається.

На мобайлі (≤768px) spread гине (T-M01): атом сам колапсує у лівий
2-рядковий wrap по ЯВНІЙ смисловій парі з `[data-srh-group]` (розбивка
задається в markup, ніколи авто-переносом), статичний і без піна (C7).
Секції на мобайлі короткі — без десктопного runway, нуль мертвих зон.
Межі актів на портреті тримає інверсія фону (T-M07), не цей атом.

## Розмітка + виклик
```html
<section class="act" data-srh-section>      <!-- секція-пас ~200vh -->
  <div class="sticky-100vh-grid-center">    <!-- sticky top:0, height:100vh - ряд у кадрі весь прохід -->
    <h2 data-srh>
      <span data-srh-group>Час рости</span> <!-- ЯВНА смислова пара = мобільні рядки -->
      <span data-srh-group>вище</span>
    </h2>
  </div>
</section>
```
```js
// десктоп: scrub по пасу секції, мобайл: лівий семантичний стек - одна точка входу
const srh = SpreadRowHeadline.create('[data-srh]', { ease: 'air', stagger: 0.06 });
await srh.ready;          // fonts.ready + wire
// або вручну: SpreadRowHeadline.create(el, { trigger: 'progress' }).set(0.5)
```

## Доведено (lab, headless-цифри)
Розділювач працює МІЖ full-bleed рендер-секціями (C11) на light/dark ритмі:
«ЧАС РОСТИ ВИЩЕ» і «НОВИЙ ТИП ДОМУ» в 200vh секціях-пасах зі sticky-супроводом
ряду + форсований 360px бокс («У ЦЕНТРІ / ЖИТТЯ») + малий маркер-хвіст.
Виміряно 1440x900: spread 699 → 1111 → 1328 → 1374 → 1382px на
p=[0/.25/.5/.75/1] (дельта 683.6px = 47.5% vw, перше слово проїжджає 342px);
act2 728 → 1088 → 1327 → 1374 → 1382px (45.5% vw); повний bbox усіх слів у
в'юпорті на всіх 5 позиціях. Dead-band скан кроком 300px: 21 позиція, 12
перевірок з актом >60% екрана, 0 мертвих смуг (v2 мав 8), ланцюг предків
sticky чистий від overflow-x:hidden. На 1280x720 обидва акти 47.5%/45.5% vw,
скан теж 0 смуг. Мобільний пакет 390x844: сторінка 4.15 екрана, максимальний
проміжок 0.22 екрана, текст-ректи від 23.4px, акти центровані, wrap
семантичний. Проби йдуть на нативному скролі; Lenis стартує після проб лише
для живого перегляду.
