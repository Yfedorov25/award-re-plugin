# case-tabs-table: один тап перескладає всю модель

Ядро стратегічної машини AIR. Таби-клітинки з чорним підкресленням-активом,
head 1.9vw, таблиця 5 рядків із right-aligned значеннями і крок 5.6vh,
результат-пари 1.9vw - все за виміряним контрактом B3. Своп = подвійна
експозиція: привид старого значення (абсолютний сiблінг у .ctt-swap
обгортці) гасне поверх нового, layout мертво стоїть. На мобайлі діє T-M19:
жодних слайдерів, лише read-only пресети на тапах.

## Виклик
```js
const ctt = CaseTabsTable.create('#ctt', {
  cases: [
    { tab: '24 метри', head: 'Квартира 24 м²',
      rows: [{ label: 'Площа', value: '24 м²' }, /* ... 5 рядків */],
      result: [{ label: 'Вхід', value: 'від 22 800 доларів' }] },
    { tab: '27 метрів', head: 'Квартира 27 м²', rows: [/* ті самі лейбли */], result: [/* ... */] }
  ],
  duration: 0.3
});
ctt.setCase(1); // програмний своп
```

## Доведено (lab, headless-цифри)
Канон-датасет smart (24/27 м², вхід 22 800, ключі 2027) на панелі #ececea.
Числа блока дзеркалять window.__PROBE прогону на 1440x900 / 390x844 /
1280x720: геометрія клітинок і рядків у контрактних допусках, контраст
≥4.5, своп із рівно 2 привидами і нульовим зсувом рядів, T-M19 пакет
чистий, CLS і дрейф якорів у межах. Точні цифри - у вердикт-звіті сесії.
