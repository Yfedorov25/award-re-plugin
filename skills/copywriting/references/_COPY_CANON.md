## Джерело правди: прод Нагірної (рішення власника 2026-07-04) + прийняті еталони smart/tauny

Рішення власника, зафіксовані письмово (закон F15: конфлікт канонічних даних = рішення
власника, один раз, письмово):

1. **Канонічна ціна Нагірної = $325k.** Інших цифр ціни для nahirna не вживати (F2/F3).
2. **Джерело правди копі-канону = ЧИННА ПРОД-копія сайту Нагірної** («на сайті нагірної вже
   копірайт правильний») + прийняті еталони smart/tauny. Де інжест фіксує конфлікт версій,
   перемагає прод-версія.
3. **Юр-чутливі claims (берег) НЕ викидаються з еталонів**: лишаються дослівно, але несуть
   позначку **«F10: юр-перевірка перед перевикористанням»**.

### Як розвʼязані 3 ⚠️-конфлікти інжесту

| Конфлікт | Рішення (прод перемагає) |
|---|---|
| Hero nahirna: стара COPY_nahirna («Найближче чуже вікно Вас не побачить», «Гортайте — день стає ніччю») vs REBUILD | Канон = прод = версія REBUILD (ЕТ-01). Старі рядки лишаються АНТИ-прикладами (класи 4, 5). |
| «Власний берег» (ЕТ-05) vs юр-півот «перша лінія / прибережна зона» | Еталони з «власний берег» лишаються дослівно (прод-рішення власника), АЛЕ кожен такий claim = «F10: юр-перевірка перед перевикористанням». На НОВИХ проєктах без юр-ОК писати «прибережна зона» / «перша лінія». |
| Бан-правило «річка, не ріка» vs прод-hero «За огорожею — ріка й дерева» | Прод-рядок канонічний дослівно (не правити). Правило «річка, не ріка» діє для НОВОЇ копі, не ретроактивно для затвердженого прод-рядка. |

Четверта чесна примітка (не конфлікт версій, а гігієна): у канон-цитатах фізично присутні
довгі тире з оригіналів. Це НЕ дозвіл на тире в живій копі: закон E1 + B16 діють завжди,
скан `grep -nP "[\x{2013}\x{2014}]"` по видимому тексту = порожньо.

## АНТИ-КЛАСИ (10)

Negative few-shot: відхилені рядки НЕ сміють зʼявитися знову. Regression-grep по видимому
тексту перед здачею (разом із bans.yaml і `_ANTISLOP_ukrainian_hard.md`):

```
grep -rniE "найближчим часом|Лишилось місце|Твоє серед них|Уже тепліше|Відпусти один критерій|Порахували кожну дорогу|Рахуйте самі|Район, як він є|день стає ніччю|не побачить" <корінь видимого тексту>
grep -rnP "[\x{2013}\x{2014}]" <корінь видимого тексту>
grep -rnwE "ти|тебе|тобі|твій|твоя|твоє|твої" <корінь видимого тексту>
```

### Клас 1. Поезія / двотактні афоризми (головний бан)
Відхилено: «Розмір ти вже знаєш. Лишилось місце.» · «Твоє серед них.» · «Уже тепліше.» ·
«Відпусти один критерій, і вони повернуться.»
Причина (власник, дослівно): **«не роби такі художні текста не будуй навколо них типу
"Розмір ти вже знаєш. Лишилось місце" бо це не за федорівим, занадта поезія це АІ-слоп,
має бути максимально легко зрозуміло для людей і передавати сенс»**.
Маркер: двотактні афоризми (речення1. речення2.), метафора-перш заголовки, рядок вимагає
перечитування. Grep: рядки вище дослівно (regression) + read-aloud тест.

### Клас 2. «Так ніхто не говорить» (заголовки-афоризми без факту обʼєкта)
Відхилено (LOCATION R4): «Порахували кожну дорогу.» · «Тут є все. Рахуйте самі.» ·
«Район, як він є.»
Причина (власник, дослівно): **«це жахливий АІ-слоп так ніхто не говорить взагалі це не
зрозуміло якось не тон оф войс наш / сенс карти показати дуже круто що є поруч»**.
Діагностика: рядок переноситься на будь-який чужий сайт без зміни = слоп. Рядок мусить
нести факт/число/дію САМЕ ЦЬОГО обʼєкта (тест Федоріва, `bans.yaml` meta_tests).

### Клас 3. Односкладність / обірваність / «тире-як-тук»
Відхилено: «Удень — строгий. Надвечір — теплий.» · «Клінкерна цегла — темна, шоколадна —
надовго» · «вікна від полудня». Вердикти джерела: «обірвано, телеграфно, тире-як-тук»;
фікс: «кожна деталь — коротка повна думка». Парцеляція-драма = слоп (закон E3).
Grep: `grep -rnP "[\x{2013}\x{2014}]"` = порожньо (E1/B16).
Нюанс-межа: короткі сильні форми ДОЗВОЛЕНІ, якщо сильна ідея, не обрубок заради «крутості»
(дозволене: іменні пари «Кухня. Вечеря.» з ЕТ-21, ритм без тире і без дієслова).

### Клас 4. Технічність замість емоції / опис механіки
Відхилено: «Глибокі навіси ховають вікна... уздовж карнизів вмикається підсвітка»
(«технічна довідка, інженерна, не про емоцію») · «Гортайте — день стає ніччю» («опис
механіки»; стало «Гортайте — настає вечір»). Механіка UI ≠ емоція сцени.

### Клас 5. Тривожність / негатив у «перевазі»
Відхилено: «Найближче чуже вікно Вас не побачить» («майже тривожно»). Перевагу подаємо
позитивною картиною (прод-фікс: «Найближче вікно сусіда — за садом», ЕТ-01).

### Клас 6. Пафос / протиставлення в лоб / бани власника
Бани: «Невелика, але власна» · протиставлення «чужа/своя», «оренда проти власності» в лоб ·
прозріння «розумієш: це твоє» · команди «Дивись», «Бачиш», «Придивись» («не його»).
Це вже закон E3 + hard_phrases у `bans.yaml`: grep кожної перед здачею.

### Клас 7. Розсинхрон голосу («ти» замість «Ви»)
Факти: cta-1 згенерувався на «ти» зі старої версії промпта, власник: **«на ви»**; живі
дефекти: smart CTA-помилки на «ти», towns scrollcue «Дізнайся більше», решта сайтів на «ви».
Фікс-процедура: ви-пас по ВСІХ текстових нодах при записі в базу.
Grep: `grep -rnwE "ти|тебе|тобі|твій|твоя|твоє|твої"` + імперативи 2-ї особи однини
(«Дізнайся», «Тапни», «Перевір», «Постав») очима.

### Клас 8. Слоп-слова в проді
«найближчим часом» = слоп, світився у 3 з 4 живих сайтів (прапорець власнику).
Grep: `grep -rni "найближчим часом"` = порожньо.

### Клас 9. Форма подачі варіантів (процесний)
Показ копі через AskUserQuestion відхилено 3×: **«не показуй мені так, а напиши текстом
різні варіанти повноцінно а не обривками через userquestion»**. Це закон E10/A5,
enforced хуком плагіна. Варіанти = повні секвенції в чаті, вибір вільною відповіддю.

### Клас 10. Структурний (не текст, а формат секції)
towns units round-1: числовий одометр на однотипному датасеті = «семантична каша», вердикт
«для таунів провал потрібно нові варіанти». Тип обʼєкта визначає units-архетип (пор. C26:
закони секції з її РОЛІ; датасет без чисел ≠ числовий хребет).

## ПРАВИЛА

Дедупліковано проти конституції. Формат: що вже закон = лише посилання; НОВЕ = тільки те,
чого в законах і базових reference-файлах нема.

### (а) Вже закон конституції: виконувати, не дублювати

- Нуль em/en-dash у видимій копі → **E1 + B16**. Скан: `grep -nP "[\x{2013}\x{2014}]"` =
  порожньо; у JS для textContent реальні символи, не HTML-entities (B16).
- Нуль поезії, «на ви», бан-лист ДОСЛІВНО в кожну версію промпта білдера → **E16**.
- Один голос на сайт → **E2**; нуль форм «ти» у видимому тексті → **B16**.
- Бани власника (парцеляція-драма, «Дивись/Бачиш», «чужа/своя»...) → **E3 + bans.yaml**.
- Конкретний образ або проста цифра, тест «сказав би живий продавець уголос?» → **E4**.
- Нуль вигаданих цитат/фактів; не приписувати читачу вік/статус; майбутній час для
  недобудованого → **E5/E6/E7 + F1-F7**.
- Укр-антислоп прогін (русизми, кліше) → **E8 + `_ANTISLOP_ukrainian_hard.md`**.
- Ліміти: hero ≤6 слів, H1 3-6, body-речення ≤12, одна думка = одне речення → **E11**.
- CTA не тисне, одна тиха дія → **E13**; ДНК хедлайнів ~70% прості → **E14**.
- Варіанти повними секвенціями в чаті, не AskUserQuestion → **E10/A5**.
- Видиме копі тільки через copy-fedoriv + self-check → **E15**; копі-до-білда → **E16**.
- Юр-перевірка claims (берег, «єдиний», власність, строки) → **F10**.
- Канонічні числа: одне джерело, конфлікт = рішення власника письмово → **F2/F15**.

### (б) НОВЕ з жнив (доповнює закони, не суперечить)

1. **Register зафіксовано: шанобливе «Ви» СКРІЗЬ** (включно з мікрокопі форм і aria-label).
   Звужує E2: для RE-сайтів власника вибір «ти АБО ви» зроблено назавжди = «Ви».
   Register = UA-офіційний-простий (Дія/Ощад/Нова Пошта), тепло, A2-B1, без канцеляриту.
   Комерція = окремий регістр: факт + вигода + число, дієслова роботи, безособово.
2. **Число-герой замість епітета** («45 квадратів без стін», «0 хвилин», «$67 тис.»).
   Формат чисел: десяткові через кому (23,76) · тисячі через пробіл ($22 800) · «м²»
   нерозривним пробілом · одна величина на одометр-рил.
3. **Довжина понад E11:** заголовки секцій 1-3 слова; абзаци 90-200 знаків; sparse
   (1-3 короткі речення), не bullet-list; активний стан.
4. **Тайтл ЗАКРИВАЄ біт вердиктом про вигоду (крапка, тиша); body/line під ним ВІДКРИВАЄ
   наступний.** Бан тайтлів-назв слайду («Планування», «Характеристики»). Акт-слово ніколи
   не каже «скрольни».
5. **CTA-бан на кнопках:** «Надіслати / ОК / Детальніше / Дізнатись більше». CTA = дієслово +
   вигода: «Записатися на перегляд», «Запитати про розтермінування», «Обрати місце в ряду».
6. **Microcopy-помилки: без оклику, позитивно** (еталон форми ЕТ-33).
7. **«Ялинки» «...», не "..."** у видимому тексті.
8. **Бан-слова з жнив** (дописати до grep-прогону, поки їх нема в bans.yaml):
   «найближчим часом» · units-лист: «ідеальний вибір», «мрія», «унікальний»,
   «ексклюзивний», «преміальний», «продуманий до дрібниць», «функціональний простір»,
   «оптимальне планування», «інвестиція у майбутнє», шаблон «не просто X, а Y» ·
   хард-стоп RE: «місто в місті», «серце міста», «квартира мрії», «новий рівень життя»,
   «елітний» · русизми: «на протязі» (→ «протягом»), «в якості» (→ «як»), «являється»
   (→ «є»), «слідуючий» (→ «наступний»), «ріка» (→ «річка»; для НОВОЇ копі, конфлікт 3).
9. **Клас B чесності (розширює F1/F4):** відсутній факт = обіцянка процедури, не
   замовчування і не вигадка: «Дати · Назвемо, коли зафіксуємо їх у документах.» (ЕТ-29).
   Плейсхолдер «⚠️ TODO» замість вигаданої цифри. Підпис генерованого медіа
   «Візуалізація · ...» = ЧАСТИНА копі (розширює F6).
10. **8 робочих формул прийнятого** (структурні патерни, дозволені до переносу між проєктами):
    - Ф1. Факт + дія + реальні назви (ЕТ-14).
    - Ф2. Контраст «Здається X. Насправді Y» (ЕТ-15).
    - Ф3. Сцена-ланцюг погляду (ЕТ-11).
    - Ф4. One-two punch: «Тут не чути сусідів. Чути воду.» (ЕТ-10).
    - Ф5. Прямий контраст цін без пафосу (ЕТ-07).
    - Ф6. Підпис стадії «дата · буденне слово стану» (ЕТ-26), не «етап 2», не поезія.
    - Ф7. Підпис POI «ТИП · N хв», назва вторинна (ЕТ-17).

## ПРОЦЕС: що реально підвищувало якість (з інжесту)

1. **Копі затверджується ДО білда** (= закон E16; народився з провалу LOCATION R1-R4).
   Робоча інверсія: (1) знайти живий еталон тону на проді → (2) вивести формулу →
   (3) переписати ВСІ рядки → (4) копі-першою в промпт ДОСЛІВНО із забороною білдеру
   редагувати + гейт grep-ом на дослівність і на em/en-dash. Architecture пройшла два
   раунди без зауважень до тексту; trust = нуль копі-ітерацій, бо скелет стояв у промпті.
2. **Старт = brief / дослівні цитати клієнта + Big Idea**, не з повітря; база reference-файлів
   цього скіла прочитана ДО першого рядка (READ-GATE у SKILL.md, закон E12).
3. **Ітерації з причиною під кожним фіксом:** що було / чому slop / що стало; named
   камертон-рядок (один екран, ЕТ-11) як мірило усього сайту.
4. **Гейти самоперевірки:** anti-slop чеклист + read-aloud + dash-скан = 0 + PLAIN-COPY
   declaration (процитувати кожен тайтл/міст назад, перевірити на поезію). При записі в
   базу: ви-пас + деш-скан.
5. **Подача варіантів повним текстом у чаті** (закон E10; AskUserQuestion відхилено 3×).
6. **Реальні числа з датасета замість прикметників; чесні фізичні факти** («спільні стіни
   гріють») замість вигаданих переваг; «⚠️ TODO» де нема факту.
7. **Ціна недомовленого закону:** units коштували 3 раунди, бо «нуль поезії» зʼявився
   тільки на round-2. Закон тону стоїть у брифі/промпті з ПЕРШОГО раунду.
8. **Конвеєр:** копі-скелет вшивається в паспорт темплейта В ПРОМПТІ (не пишеться після
   коду) → результат приходить уже з копі.
