### Мобільний hero (покадрово)
- сек 1–9: чорна канва, гігант «SILVER PINEWOOD» грубим гротеском ламається на 2 рядки (3-рядк. десктоп стиснуто). Вертикальна біла ЛІНІЯ-роздільник стоїть зліва і покадрово ЇДЕ ВПРАВО через екран — анімована завіса, що відкриває wordmark (на десктопі вона статична!). Лого тримається статичним ~12с (текст=головний обʼєкт), БЕЗ фото-вежі (порт віддає весь екран тексту).
- сек 13: «RESIDENCES» доклеюється 3-м рядком, виходить за нижній край (навмисна обрізка).
- сек 14–15: бежево-коричнева панель НАПОВЗАЄ з CAPS-факт-абзацом, wordmark-привид (light-grey, напівпрозорий) ПОЗАДУ тексту. Заїжджає фото-колаж (катер+wake / жінка з конем / чоловік) — десктопний розкиданий колаж у вертикальний стек.
- climax: повноекр. рендер вежі з ЧЕРВОНОЮ АРКОЮ full-bleed, header CONTACT US/MENU, тайтл «SILVER PINEWOOD RESIDENCES», лейбл «QUIET LUXURY» внизу-справа + ↓.

### Зникло на мобільному
Курсор-лінза (/architecture); ховер-превʼю amenities; ховер-фільтр точок карти; меню-ховер фарбує слово помаранчевим; spread-розгін слів (повітря зникає); side-by-side wordmark+фото (→ 2 екрани).

### Нове на мобільному
Анімована вертикальна лінія-завіса в hero; горизонтальна таб-карусель категорій під картою; нижня док-плашка-tooltip для POI; scroll-pin із внутрішнім progress (/architecture); ОБРІЗКА АКТ-СЛІВ краями порту як свідомий прийом; capsule-aware layout (CTA/cookie над браузер-капсулою); вертикальні фото-стеки замість розкиданого колажу.

### Копі на мобільному
Тон 1:1: фактологічні CAPS-абзаци, нуль прикметникових гірлянд, спокійна інвентаризація. Жодного скорочення під моб — повні 2-3 реченнєві блоки. Лейбл «QUIET LUXURY». Акт-слова голі іменники: TERRITORY, ARCHITECTURE, LOBBY, NATURAL MOVEMENT, PRIVATE TERRACES, TIMELESS NEOCLASSICISM. Highlight коричневим на ключовій фразі («WITH EXPANSIVE STEPPED TERRACES»). Amenities голі іменники списком. Форма: REQUEST A CALL, NAME*/PHONE*, REQUEST. Футер: SALES OFFICE адреса, OPEN DAILY 9-21, ↑, 2026 © …, WEBSITE BY VIDE INFRA.

### T-ID кандидати (моб)
- M_HERO_LINE_CURTAIN — вертикальна лінія свайпає зліва-направо, відкриваючи wordmark (статичний роздільник→вступна завіса). no-WebGL ✓ (translateX + clip).
- M_WORDMARK_SPLIT — 3-рядк. wordmark→2 рядки + 3-й (RESIDENCES) свідомо обрізаний нижнім краєм. no-WebGL ✓ (clamp + overflow).
- M_ACTWORD_BLEED — акт-слова ширші за порт, краї обрізаються (кінематичне «не вміщається»). no-WebGL ✓ (font-size>100vw + overflow:hidden).
- M_PANEL_SLIDE_FACT — бежево-коричнева факт-панель наповзає + CAPS-line-reveal + wordmark-привид позаду. no-WebGL ✓ (translateY + stagger opacity).
- M_PHOTO_STACK_COLLAGE — розкиданий колаж→верт. фото-стек зі зміщеними рамками. no-WebGL ✓ (flex-column + per-item parallax y).
- M_CAT_TAB_CAROUSEL — горизонтальна скрол-стрічка категорій-табів під картою, активний фільтрує POI. no-WebGL ✓ (overflow-x scroll-snap + state).
- M_POI_DOCK_TOOLTIP — tap маркер → чорна нижня док-плашка зі списком об'єктів. no-WebGL ✓.
- M_SECTION_PIN_PROGRESS — секція тримається ~15 кадрів як запінена сторінка з внутр. progress. no-WebGL ✓ (sticky + scroll-progress).
- M_ARROW_THUMB_SLIDER — full-bleed рендер + ‹ › тап-стрілки + рядок thumbnail-прев'ю під CAPS-панеллю. no-WebGL ✓.
- M_BROWSER_CHROME_AWARE — layout тримає CTA/cookie/footer над плаваючою браузер-капсулою. no-WebGL ✓ (safe-area/bottom padding).
- M_NOUN_LIST_SCROLL — гігант-список іменників ◉, фото→scroll/tap-reveal. no-WebGL ✓ (IntersectionObserver).
