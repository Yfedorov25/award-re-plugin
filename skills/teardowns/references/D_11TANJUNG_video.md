## МОВА САЙТУ
1. **Прелоадер:** чорна канва зі СКРУГЛЕНИМИ КУТАМИ (вʼюпорт як картка) +
   %-лічильник → величезний курсивний лого «11 tanjung» → осідає в hero.
2. **Hero:** рендер вілли, ЛОГОТИП-ОВЕРЛЕЙ гігантським італік-серіфом ПОВЕРХ
   фото (типографіка як графічний шар); координати/контакти по кутах;
   **SOUND ON/OFF тумблер** (амбіент-звук = окремий шар досвіду);
   SCROLL TO EXPLORE.
3. **Rounded-canvas секції:** великі «полотна-картки» зі скругленими кутами
   (тауп, чорна) — секція висувається як аркуш. Канва = розпізнавана одиниця
   композиції замість прямих full-bleed стиків.
4. **Кільця-тріо:** /01 LIVE WITH STANDARD · /02 LIVE WITH STYLE · /03 LIVE
   UNCOMPROMISED — три контурні кола, кожне ЗАЛИВАЄТЬСЯ товстим кільцем
   (radial progress) по черзі скролом = зміст глав.
5. **Глави-фрази:** «Live / with / Standard|Style|Uncompromised» — слова фрази
   РОЗКИДАНІ по повноекранному кадру на різних глибинах (інтерлів з медіа),
   кожна глава = новий кадр вілли; фото проявляється З БЛЮРУ (blur→sharp
   reveal). Фразова естафета крізь медіа.
6. **Types of Villas карусель:** картка типу = фото + «3-STOREY COURTYARD
   GARDEN VILLA» + SQFT + спеки (4 BEDROOMS · 1 MAID ROOM · BATHROOMS ·
   POWDER ROOM) + кнопка FLOOR PLAN ↗; стрілки prev/next.
7. **Facilities-акордеон:** ряд ВЕРТИКАЛЬНИХ фото-смуг різної ширини;
   скрол/ховер РОЗСУВАЄ активну смугу (SUNSET DECK / FITNESS ZONE / WINE
   LOUNGE) — розсувні панелі замість гріда.
8. **Карта-мінімал:** білий ЛІНІЙНИЙ план доріг на тауп-канві (рукописна
   естетика, лейбли района) + адреси PROJECT LOCATION / SALES GALLERY.
9. **Футер:** чорна rounded-канва «Discover / Exclusive» італіком + КОЛО
   CONTACT US + BOOK A VISIT / SHOW UNIT + смуга BACK TO TOP.

## ДЕЛЬТИ ГРАМАТИКИ
- L1: **rounded-canvas секція** (полотно-картка зі скругленими кутами).
- L1: **facilities-акордеон** вертикальних фото-смуг.
- L2: **логотип-оверлей** поверх hero-медіа; **blur→sharp reveal** фото.
- L3: **фразова естафета глав** (слова однієї фрази розкидані по кадру,
  глава = кадр+фраза); **кільця-тріо radial-fill** як зміст.
- L4: **sound-тумблер** (амбіент як шар).
- Архетип: **types-карусель** (тип-картка: фото+sqft+спеки+floor-plan CTA).
- Футер-архетип: rounded-канва + контакт-коло + back-to-top смуга.
