## 1. МОДЕЛЬ ШАРІВ (layer stack)
Кожна секція складається з шарів. Один прийом = один шар. Шари типізовані:

| Шар | Що це | Приклади прийомів (повні T-ID — у [_REGISTRY_TID.md](./_REGISTRY_TID.md)) |
|---|---|---|
| L1 BASE-MEDIA | чим зайнятий кадр | full-bleed still · frame-scrub canvas · відео · SVG-план · реальний фасад · повноекранний дек з лічильником + line-ticks (SAISEI) · rounded-canvas «полотно-картка» (11TANJUNG) · facilities-акордеон вертикальних смуг (11TANJUNG) · інтро-мозаїка дистанцій: плитки різних планів складаються в діагональний колаж (Springs) |
| L2 MEDIA-OVERLAY | що живе ПОВЕРХ медіа | scrim-градієнт · паралакс-у-рамці · day→night dissolve · ghost-цифра · світло/glow · бренд-3D-обʼєкт наскрізний (AIR спіраль/сфера · SP хромові камені · ERA граніт-куб) · матеріал-як-3D-обʼєкт біля фото застосування (ERA, вирішення F-20) · silk-wave бренд-стрічка на градієнтній канві (Springs) · color-zone overlays на реальному аеро + хв-картки (AIR) · логотип-оверлей поверх hero (11TANJUNG) · blur→sharp reveal (11TANJUNG) |
| L3 TEXT-CHOREO | як заходить текст | split-line .ln>span · act-слово clip · counter · титри-секвенція · text-shelf · scatter→assemble літер (SAISEI) · text-photo interleave у display-рядках (SAISEI) · тришаровий лейбл (ієрогліф+ромадзі+переклад) · spread-row заголовок: слова розведені по ширині, зʼїжджаються скролом (AIR, системний act-розділювач) · kinetic nav-letters з країв вʼюпорта (AIR) · фразова естафета глав (11TANJUNG) · кільця-тріо radial-fill як зміст (11TANJUNG) · акти-імперативи кольором бренду (ERA: BASK IN THE GLORY) · ghost-CAPS за каруселлю (ERA) · список-іменників величезним з ховер-превʼю (SP amenities) |
| L4 MICRO | дрібна жизнь | self-draw лінії · пілюлі-якорі · бейджі · курсор-режими · ховер-стани · sound-тумблер default-OFF (11TANJUNG) · гігантське число-факт у lifestyle-слайді (AIR: 400 STORES, 3 MIN) · курсор-лінза: кругла пляма-акцент за мишею (SP) · ховер-підписи амбіент-зон на фото будівлі (Springs) · плаваюче запрошення пікера на контент-сторінках (ERA) |
| L5 SEAM-IN / SEAM-OUT | як секція приходить і віддає естафету | theme-flip · light-шов · sticky-under · нитка · спільний елемент |

**Формула (закон C1):**
- flagship-секція (hero, visual-search, головна історія): L1 + ≥2×L2 + L3 + ≥1×L4 + обидва L5 → **5-7 шарів**
- службова секція (умови, факти, легал): L1-light + L3 + L4 → **3 шари**
Стек шарів записується в motion-score РЯДКОМ (не прозою): `L1 фасад-рендер · L2 scrim+паралакс+ghost · L3 split-line · L4 пілюлі+попавер · seam-in light-шов / seam-out нитка`.

### МЕТА-ПАТЕРН ЕКСПОЗИЦІЇ (підтверджено 6/6 відео-тірдаунів)
Базова одиниця розповіді всіх еталонів: **[АКТ-заголовок] + [повноекранне медіа] +
[ОДИН малий факт-абзац]**. Розрізняється лише ТОН акта: Springs = іменник-стан
(Wellness), SP = іменник-місце (TERRITORY), ERA = поетичний імператив (GO TO THE
LIGHT), SAISEI = сентенція (EVERY LINE TELLS A STORY), 11T = фраза-глава (Live with
Style). Копірайт-правило: бренд-рамка-рефрен повторюється hero→footer (ERA, SAISEI);
факти живуть ДРІБНИМ на картках поверх медіа, ніколи довгими колонками.

## 5. ПРОЦЕДУРА КОМПОЗИЦІЇ СЕКЦІЇ (виконати, не прочитати)
1. Визнач роль → візьми архетип-стек як БАЗУ.
2. Звір з партитурою дистанцій: яка дистанція тут, чи не дубль сусідів.
3. Підбери варіації шарів з реєстру (2-4 варіанти СТЕКІВ, не «прийомів») → прототипи.
4. Запиши обраний стек РЯДКОМ у motion-score + обидва шви.
5. Перевір лічильно: шарів ≥5 (flagship) / ≥3 (службова); прийом не вживається
   втретє на сайті; пін-бюджет не пробитий; спосіб шва не повторюється.
6. **Мобільний переклад (обов'язково, не «потім»):** для КОЖНОГО обраного T-ID звір з L6 MOBILE
   (_REGISTRY_TID, T-M01…T-M12) — який закон трансформації застосувати на ≤640px. Запиши мобільну
   форму в той самий рядок motion-score через `gsap.matchMedia()` / media-query. Десктоп лишається 1:1.

## 6. МОБІЛЬНИЙ ЗАКОН (L6 — портрет ≤640px)
> Підтверджено 4 моб-тірдаунами (SAISEI/AIR/SPRINGS/SilverPinewood). Award-студії НЕ спрощують — ПЕРЕКЛАДАЮТЬ.
- **Немає горизонталі.** Усе паралельне → послідовне; усе рознесене по ширині (spread-row) → лівий стек
  по смисловій парі (T-M01); 2-col → vertical stack (T-M03); z-паралакс → вертикальна паралакс-стрічка (T-M04).
- **Драматургію тримає світло, не простір.** Бо spread-розгін гине, межі актів = різка інверсія фону (T-M07);
  overshoot-settle акт-СЛОВА лишається 1:1; push-over → crossfade (T-M05); слайдер → pinned-scroll (T-M06).
- **Кожен hover → tap (T-M09).** Курсор-only прийоми (лінза) випадають повністю; попавери/превʼю → tap-reveal;
  бічні панелі/ховер-картки → нижня sticky таб-стрічка + док-плашка (T-M08).
- **Копі й драматургія — 1:1.** Портрет НІЧОГО не вкорочує в текстах. Гасла ламаються по смисловій парі,
  не рвано. Меню = дзеркало футера (T-M11). Браузер-капсула знизу — частина layout (T-M12, safe-area).
- **Чого НЕ знято (діра):** мобільна поведінка ВЛАСНИХ сайтів і моб-версії ERA/Ever/11T. Кандидати на тірдаун.

## 8. NIGHT-RELIGHT КОНТРАКТ (день↔ніч, закони G14-G19 — найбільша діра, towns F-25/26/27)
Перед БУДЬ-ЯКОЮ нічною генерацією інтер'єру — 5 пунктів у промпт ОБОВ'ЯЗКОВО:
1. **Нуль сонця:** «remove ALL sunlight/sun rays/bright light pools on floor+furniture — no sun exists at night».
2. **Темна сцена:** «scene DARK, low exposure overall».
3. **Світло тільки від ламп:** «light ONLY from interior lamps + LED cove — warm pools AROUND each source, rest falls to shadow».
4. **Інвентар locked:** «do NOT add lamps/pendants/chandeliers not in the day reference; only EXISTING fixtures emit light; every object identical to day frame».
5. **i2i з фінального дня** (не оригінал окремо) + night-ref як стиль-якір (G17).
ДЕНЬ-промпт дзеркально: «daylight is the ONLY light; LED cove + all artificial OFF/unlit; no glowing strips» (G15).
Поверх (G18): «single seamless photo, NOT diptych, no vertical seam». Камера по поверху (G19): 1-й рівень землі / 2-й вид вниз.
