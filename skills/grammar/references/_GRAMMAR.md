# _GRAMMAR — граматика комбінування прийомів (v1, каркас)
> ЛІКУЄ головну хворобу v0.2: «меню прийомів без правил поєднання» (мета-патерн
> 28 провалів: джуніор = 1 прийом + дрібниці; Ever = 5-7 прийомів нашарованих).
> Схема розрахована на поповнення з відео-тірдаунів (/award-re:learn video-teardown):
> кожен новий сайт додає рядки в шари/шви/архетипи, НЕ міняючи модель.
> Якщо сайт не лягає в модель — лагодимо МОДЕЛЬ (і пишемо чому в CHANGELOG-GRAMMAR).

## 1. МОДЕЛЬ ШАРІВ (layer stack)
Кожна секція складається з шарів. Один прийом = один шар. Шари типізовані:

| Шар | Що це | Приклади прийомів (T-ID після міграції реєстру) |
|---|---|---|
| L1 BASE-MEDIA | чим зайнятий кадр | full-bleed still · frame-scrub canvas · відео · SVG-план · реальний фасад |
| L2 MEDIA-OVERLAY | що живе ПОВЕРХ медіа | scrim-градієнт · паралакс-у-рамці · day→night dissolve · ghost-цифра · світло/glow |
| L3 TEXT-CHOREO | як заходить текст | split-line .ln>span · act-слово clip · counter · титри-секвенція · text-shelf |
| L4 MICRO | дрібна жизнь | self-draw лінії · пілюлі-якорі · бейджі · курсор-режими · ховер-стани |
| L5 SEAM-IN / SEAM-OUT | як секція приходить і віддає естафету | theme-flip · light-шов · sticky-under · нитка · спільний елемент |

**Формула (закон C1):**
- flagship-секція (hero, visual-search, головна історія): L1 + ≥2×L2 + L3 + ≥1×L4 + обидва L5 → **5-7 шарів**
- службова секція (умови, факти, легал): L1-light + L3 + L4 → **3 шари**
Стек шарів записується в motion-score РЯДКОМ (не прозою): `L1 фасад-рендер · L2 scrim+паралакс+ghost · L3 split-line · L4 пілюлі+попавер · seam-in light-шов / seam-out нитка`.

## 2. ПАРТИТУРА ДИСТАНЦІЙ (закони C3/C4/C15)
Перед білдом — таблиця по всіх секціях:
| Секція | Дистанція (аеро/повний/середній/макро/інтер'єр) | Повтор? | Що перетікає далі |
Правила: повний план обʼєкта ≤2 рази; сусідні секції не повторюють дистанцію;
нема макро в ассетах → згенерувати чесне макро (кропи мастерів, закон G8).

## 5. ПРОЦЕДУРА КОМПОЗИЦІЇ СЕКЦІЇ (виконати, не прочитати)
1. Визнач роль → візьми архетип-стек як БАЗУ.
2. Звір з партитурою дистанцій: яка дистанція тут, чи не дубль сусідів.
3. Підбери варіації шарів з реєстру (2-4 варіанти СТЕКІВ, не «прийомів») → прототипи.
4. Запиши обраний стек РЯДКОМ у motion-score + обидва шви.
5. Перевір лічильно: шарів ≥5 (flagship) / ≥3 (службова); прийом не вживається
   втретє на сайті; пін-бюджет не пробитий; спосіб шва не повторюється.
