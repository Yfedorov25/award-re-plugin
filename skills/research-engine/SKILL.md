# Research Engine

Дослідження ринку/конкурентів/ЦА під капотом фази 0. Підкоряйся `../../CLAUDE.md` (§1: конкуренти=СЕНСИ, ніколи візуал; §8: цитуй, не вигадуй).

## Каскад інструментів (легке → важке, під задачу)
1. **WebSearch + WebFetch** (завжди, без налаштувань) — знайти 3-7 конкурентів, прочитати їхні сайти/ціни/меседжі/слабкі місця, ринкові тренди, ЦА-сигнали.
2. **Browser / Chrome-розширення / gstack browse** — глибокий живий зонд топ-3 конкурентів (DOM/копі/скріни). Як ми робили з Vide Infra. Потребує browse-бінарника.
3. **Apify / scrape-MCP** — масовий збір (відгуки/оголошення/форуми про болі ЦА). Потребує Apify-ключа/MCP — перевір наявність, інакше пропусти.
4. **Higgsfield MCP** — візуальні референси/мудборди стилю ніші (для розуміння «дорогого вигляду», НЕ для копіювання конкурентів).

## Що зібрати
- Конкуренти (3-7): хто, позиціонування, ціни, меседжі, слабкі місця.
- ЦА-сигнали: хто купує, якою мовою говорять, що шукають.
- Болі/заперечення (з реальних джерел: відгуки/форуми).
- Візуальні коди ніші (що читається дорого/дешево).

## Правила
НІКОЛИ не вигадувати — кожен факт із джерелом (URL/цитата). Конкуренти впливають ЛИШЕ на сенси (стратегію), не на наш візуал/прийоми (рівень = Vide Infra). Результат → у brief.md (фаза 0).
